# Trade Digest 기능 아이디어

작성일: 2026-11-16 · 작성자: 정주연 · 관련 문서: [PLAN.md](PLAN.md)

Trade Digest 한 페이지에 들어갈 기능을 모두 적은 문서다. 무엇을 언제 만들지는 PLAN.md의 "만드는 순서"를 따른다.

## 한눈에 보기
| 묶음 | 기능 | 한 줄 설명 | 단계 |
|---|---|---|---|
| 핵심 | 한 장 요약 | 주장 / 근거 / 한계를 한 장으로 | 1 |
| 핵심 | 문장별 원문 쪽수 | 요약 문장마다 쪽수 + `쪽수 확인됨` 표시 | 1 |
| 핵심 | 두 입구 | 보고서 서가(검수 완료) + 내 PDF 바로 요약(검수 전) | 1 |
| 한 가지 더 | A. 숫자 → 데이터로 확인 | 보고서 숫자 옆에 Tradeweave·Policyline 링크 | 1 |
| 한 가지 더 | C. 한계 점검표 | 보고서가 가정한 것, 빠진 것, 불확실한 것 체크리스트 | 2 |
| 부가 탭 | 정책 용어 사전 | 보고서·뉴스에 나오는 통상 용어를 한 줄 풀이 + 출처 | 3 |
| 한 가지 더 | B. 같은 질문, 다른 기관 | 같은 질문에 WTO·IMF·OECD 등이 각각 뭐라고 하는지 나란히 | 4 |
| 부가 탭 | 보고서 달력 | 주요 기관 보고서 발표 일정 | 4 |

## A. 보고서 숫자 → 데이터로 확인
- **무엇**: 요약의 "근거" 칸에 나오는 숫자 중 나라·품목 교역과 관련된 것에 `데이터로 직접 보기` 링크를 붙인다.
  - 나라 교역 상대국 쏠림 → Tradeweave 해당 나라 화면
  - 특정 정책 전후 교역 → Policyline 해당 정책 카드
- **왜**: Trade Data Lab의 "읽고 → 확인하고 → 깊게 본다" 흐름을 한 화면에서 보여 준다.
- **주의**
  - 보고서 숫자와 우리 데이터는 **출처·기준이 다를 수 있다.** 값이 다르면 맞추지 않고, "기준이 다름: 보고서 ○○ / Tradeweave CEPII BACI 2024"처럼 둘 다 보여 준다.
  - 이어 줄 화면이 없는 숫자에는 링크를 달지 않는다.
- **자료**: 서가 JSON의 근거 항목마다 `link: { service, target }`. 바로 요약(②)에는 붙이지 않는다(검수 전이라 잘못 이어질 수 있음).

## C. 한계 점검표
- **무엇**: 보고서마다 같은 질문 목록으로 점검한다.
  1. 기준 기간·자료 시점은 언제인가?
  2. 전망이라면 어떤 가정을 깔고 있나? (예: 유가, 관세 수준)
  3. 다루지 않은 나라·품목·주제는?
  4. 보고서 스스로 밝힌 불확실성·위험 요인은?
  5. 숫자가 추정치인지 확정치인지?
- **화면**: 질문마다 `보고서에 적혀 있음 (쪽수)` / `보고서에 없음` / `판단 어려움` 세 가지 중 하나 + 한 줄 설명.
- **원칙**: 내 의견이 아니라 **보고서에 적힌 것**을 기준으로 채운다. "보고서에 없음"도 하나의 정보로 보여 준다.
- **범위**: 서가 보고서만. 바로 요약에는 2단계 이후 자동 초안을 붙일지 따로 정한다.

## B. 같은 질문, 다른 기관
- **무엇**: 질문 하나(예: "올해·내년 세계 상품 교역량은 얼마나 늘어날까?")에 기관별 답을 카드로 나란히 놓는다.
- **카드에 들어갈 것**: 기관, 보고서 이름, 발행일, 숫자, **지표 정의**(상품 교역량 / 상품·서비스 교역량 / 교역액 등), 기준연도, 원문 쪽수.
- **원칙**
  - 지표 정의가 다르면 같은 줄에서 비교하지 않고 `정의가 달라 직접 비교 불가`를 표시한다.
  - 누가 맞았는지 판정하지 않는다. "어디서 같고 어디서 다른지"만 보여 준다.
  - 발행 시점이 다르면(예: 4월 vs 10월) 그 차이를 함께 적는다.
- **자료**: 질문당 기관 2~4개. 서가에 있는 보고서를 우선 쓴다. 작업량이 가장 커서 4단계로 둔다.

## 정책 용어 사전 (부가 탭)
- **무엇**: 상계관세, 반덤핑관세, 수출통제, 301조, 교역조건, 경상수지 같은 용어를 한 줄 쉬운 말 + 조금 긴 설명 + 출처로 정리한다.
- **연결**: 요약 화면에서 용어에 밑줄 → 누르면 사전 풀이. 사전에서는 "이 용어가 나온 보고서" 목록.
- **출처**: WTO·정부기관 용어집 등 공식 설명을 우선. 출처 없는 풀이는 넣지 않는다.
- **범위**: 처음 20개 안팎. Trade News Room 용어 사전과 겹치는 부분은 나중에 하나로 합칠지 정한다.

## 보고서 달력 (부가 탭)
- **무엇**: WTO·IMF·OECD·World Bank·KITA·KOTRA 주요 정기 보고서의 발표 일정과 지난 발표 기록.
- **화면**: 월별 목록. 지난 발표는 서가 보고서로 이어지고, 다가오는 발표는 날짜·기관·보고서 이름만.
- **원칙**
  - 날짜는 **기관이 공식 공개한 일정**만 쓴다. 공지 링크와 확인한 날을 함께 적는다.
  - 공식 일정이 없으면 "예년 ○월 발표" 같은 추측을 날짜처럼 넣지 않는다. 필요하면 `일정 미공개`로 둔다.
- **갱신**: 달력 자료는 손으로 고치는 JSON 한 파일. 자동 수집은 나중에 정한다.

## 모든 기능 공통
- 숫자 옆에는 출처, 기준 기간, 단위를 붙인다. 보고서 숫자를 고치거나 추정하지 않는다.
- 보고서 주장은 "보고서는 ~라고 본다"로 쓰고, 사실처럼 단정하지 않는다.
- 연습용 값을 쓰면 화면과 파일 모두에 "가상"을 붙인다.
- 개인정보를 모으지 않는다. 올린 PDF와 요약은 저장하지 않는다.

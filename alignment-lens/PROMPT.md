> 사용법: 아래 `---` 선 밑의 내용을 통째로 복사해 AI 코딩 도구(Claude Code, Cursor, ChatGPT, v0, Bolt 등)에 붙여 넣는다.

# 역할

너는 데이터 시각화 웹서비스를 만드는 개발자다. 아래 명세대로 **Alignment Lens**라는 정적 웹서비스를 만든다. 명세에 없는 것은 지어내지 말고, 정할 수 없는 것은 나에게 물어본다.

# 서비스 한 줄 설명

두 나라를 고르면, 유엔총회 투표로 잰 두 나라의 **외교 거리**와 두 나라 사이 **교역 비중**이 1995년부터 해마다 어떻게 변했는지 같은 시간축 위에 나란히 보여 준다. 화면은 "같은 시기에 함께 움직였다"까지만 말하고, 원인은 단정하지 않는다.

- 핵심 질문: 정치적으로 가까운 나라끼리 교역 비중이 더 큰가? 그 관계는 시간이 지나며 강해졌나?
- 대상: 해외영업 신입, 국제통상·국제정치 관심자, 정책대학원 지원 준비생
- 첫 화면에서 할 단 하나의 행동: 두 나라 고르기

# 반드시 지킬 원칙

1. **지어낸 숫자 금지.** 화면의 모든 숫자는 아래 두 원자료에서 계산한 값이어야 한다. 원자료를 받을 수 없는 환경이면 데이터를 지어내지 말고, 데이터를 만드는 스크립트를 먼저 작성한 뒤 나에게 실행을 요청한다.
2. 예시·시안에 임시 숫자가 꼭 필요하면 화면과 파일 모두에 **"가상"** 표시를 붙인다.
3. 화면의 모든 숫자 옆(또는 그래프 아래)에 **출처와 기준연도, 자료 판 번호**를 붙인다.
4. **원인 단정 금지.** 화면 문구에 "~때문에, ~로 인해, ~의 결과로, 영향을 미쳤다, 효과가 있었다, 사이가 좋다/나쁘다, 우방/적대국"을 쓰지 않는다. 대신 "같은 시기에, 함께 움직였다, 반대로 움직였다, 투표 기준으로 가깝다/멀다, 상관(원인 아님)"을 쓴다. 다 만든 뒤 금지어를 검색해 결과가 0인지 확인한다.
5. 개인정보 수집, 로그인, 방문자 추적, 분석 스크립트 금지. 마지막으로 본 쌍 정도만 localStorage에 둘 수 있고, localStorage가 막혀도 정상 동작해야 한다.
6. API 키 같은 비밀은 필요 없다. 만약 생기면 `.env`에만 두고 코드·저장소에 넣지 않는다.
7. AI가 해석 문장을 자동으로 지어내 화면에 넣지 않는다. 해석은 사람이 검수해 JSON에 넣은 것만 보여 준다.

# 데이터

## ① 유엔총회 투표 · 이념 위치 점수
- 자료: *United Nations General Assembly Voting Data* (Erik Voeten Dataverse), Harvard Dataverse, `doi:10.7910/DVN/LEJUQZ`
- 라이선스: CC0 1.0. 그래도 인용한다: Bailey, M. A., Strezhnev, A., & Voeten, E. (2017). Estimating Dynamic State Preferences from United Nations Voting Data. *Journal of Conflict Resolution*, 61(2).
- 2026-11-17에 확인한 최신 판: 34판, 이념 위치 점수 파일 `IdealpointestimatesAll_Jun2024.csv`(제1–78차 회기). **시작할 때 더 새 판이 있는지 확인**하고, 쓴 판을 `data/meta.json`에 적는다.
- 단위: 나라 × 회기. 파일의 회기·연도 열을 확인해서 교역 연도와 맞춘다(회기는 9월에 시작). 어떤 열을 연도로 썼는지 meta.json과 방법 페이지에 적는다.
- 점수는 다시 추정하지 않고 그대로 쓴다.
- 보조 지표: 같은 Dataverse의 동의 비율(agreement) 파일. "더 보기"에서만 쓴다.

## ② 교역 · CEPII BACI HS92
- 자료: CEPII BACI, **HS92판**(1995년부터 이어지는 시계열이 필요해서). 다운로드: https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=37
- 라이선스: Etalab Open Licence 2.0 (출처 "BACI, CEPII" 표시)
- 구조: 연도별 CSV, 열은 연도 `t`, 수출국 `i`, 수입국 `j`, 품목 `k`(HS 6자리), 금액 `v`(천 미국 달러), 수량 `q`. 나라 코드는 함께 들어 있는 `country_codes_*.csv`로 ISO3에 연결한다.
- BACI는 양쪽 신고값을 하나로 맞춘 값이다(한 거래에 숫자 하나). 쓴 판 번호(예: V202601)를 화면에 표시한다.
- 원자료(CSV 수 GB)는 `raw/`에 두고 `.gitignore` 한다. 저장소와 배포에는 계산 결과 JSON만 올린다.

## ③ 나라 코드 맞추기
- ISO3 문자 코드를 기준으로 두 자료를 맞춘다. 맞지 않는 나라는 `data/code-fixes.json`에 {원래 코드, 바꾼 코드, 이유}로 남긴다.
- 해체·통합된 나라(옛 유고슬라비아, 수단·남수단 등)는 자료가 있는 기간만 쓰고, 화면에 "이 기간에는 자료 없음"을 표시한다.
- BACI의 `Other Asia, nes`(코드 490)는 대만으로 표시한다. 대만은 1971년 이후 유엔 투표 자료가 없으므로 외교 거리는 비우고 "투표 자료 없음"으로 표시한다. 교역 비중의 분모(전체 교역)에는 포함한다. 유엔 비회원·옵서버도 같은 방식.

## ④ 기간
1995년부터 투표 자료의 마지막 해까지. 교역 자료가 더 길면 그 해들은 교역 비중만 그리고 외교 거리는 비운다.

# 계산

- **외교 거리** `dist(A,B,t) = |score(A,t) − score(B,t)|`
- **교역 비중** `share(A→B,t) = (BACI에서 i=A,j=B 금액 합 + i=B,j=A 금액 합) ÷ (A의 전체 수출 + 전체 수입)` × 100. 방향이 있다. 쌍 화면에서는 A에게 B의 비중, B에게 A의 비중을 모두 보여 준다. 보조로 수출 비중·수입 비중을 따로.
- **구간 변화**: 마지막 3년 평균 − 처음 3년 평균. 어떤 연도를 평균했는지 화면에 적는다.
- **같이 움직인 정도**(3단계): 한 나라 기준으로, 해마다 상대국들의 외교 거리 순위와 교역 비중 순위의 스피어만 순위 상관. 선 하나로 보여 주고 "상관이며 원인이 아님"을 항상 붙인다. 회귀분석·중력모형은 하지 않는다.
- **빠진 값**: 점수 없는 해는 `null`. 앞뒤 값으로 메우지 않는다. 그래프 선은 끊어서 그린다. 교역 기록이 없는 쌍은 0과 구분해 "기록 없음".
- 아주 작은 상대국(기준값은 meta.json에 적고 기본 0.01%)은 산점도에서 흐리게, 표에서는 기본 숨김.
- "거의 같았다"의 기준(예: 변화가 처음 값의 5% 이내)은 meta.json에 상수로 두고 방법 페이지에 그대로 보여 준다. 기준값은 나에게 확인받는다.

# 기술 구조

- **빌드 없는 정적 사이트.** `index.html` 하나 + 바닐라 JavaScript + SVG 그래프. 프레임워크 없이. 외부 라이브러리를 쓰면 정확한 버전으로 고정하고 CDN(cdnjs, jsDelivr, unpkg) 주소를 쓴다.
- 서버 함수·데이터베이스·로그인 없음. Vercel에 Root Directory `alignment-lens`로 그대로 배포된다.
- 데이터는 파이썬 스크립트로 미리 계산한다(pandas 사용 가능).
- 한/EN 전환, 다크/라이트 전환(시스템 설정 따름 + 버튼), 휴대폰 375px 너비에서 가로 스크롤 없음.
- 주소의 `#` 뒤로 화면 전환(새로고침해도 같은 화면).

쌍 화면은 두 나라 파일만, 한 나라 화면은 그 나라 파일만 불러온다.

# 화면

## ① 첫 화면 `#/`
- 메뉴: 서비스 이름 · 방법 · 출처 · 한/EN · 다크/라이트
- 큰 제목 "가까운 나라끼리 더 많이 교역하게 되었나?" + 한 줄 설명
- 나라 A, 나라 B 검색 상자(한/영 이름, ISO3로 검색) + "나란히 보기" 버튼
- 예시 쌍 칩 3개(이름만, 숫자 없음). 예: 한국–중국, 한국–미국, 독일–러시아
- 그 아래 기능 소개 3줄과 출처 한 줄

## ② 쌍 화면 `#pair/{A}/{B}`
- 머리줄: 두 나라 이름, 기간, 출처 배지, "A와 B 바꾸기"
- **위 그래프**: 외교 거리(선 하나). 세로축 이름 "외교 거리 · 클수록 멂(유엔총회 투표 기준)"
- **아래 그래프**: 교역 비중(선 두 개: A에게 B, B에게 A). 선 끝에 이름표를 직접 붙인다
- 두 그래프는 같은 가로축(연도), 위아래로 배치. **이중 세로축 그래프 금지.** 마우스를 올리거나 탭하면 두 그래프의 같은 연도에 세로선과 값이 함께 뜬다
- 그래프 바로 아래 고정 문구: "두 선은 같은 시기의 변화를 보여 줄 뿐, 원인을 뜻하지 않습니다."
- **사실 / 해석 / 불확실** 세 칸 카드 (아래 규칙)
- 더 보기: 동의 비율 그래프, 수출·수입 비중 따로, CSV 내려받기(화면 값 + 출처 줄), Tradeweave 링크 `https://trade-weave.vercel.app/#see/{A}/export` (실제 주소는 나에게 확인)

## ③ 한 나라 화면 `#country/{A}/{year}`
- 연도 슬라이더(1995 ↔ 최신) + 재생 버튼
- 산점도: 가로 = 외교 거리, 세로 = 교역 비중(로그 눈금), 점 = 상대국. 점 크기는 쓰지 않는다. 점을 누르면 쌍 화면으로
- 표: 상대국 · 외교 거리 · 교역 비중 · 처음 대비 변화. 열 머리를 눌러 정렬
- (3단계) 같이 움직인 정도: 연도별 순위 상관 선 + "상관이며 원인이 아님"

## ④ 방법 `#method`
계산식, 자료 판, 연도 맞추는 방법, 나라 코드 처리(대만·해체 국가 포함), 기준값, 한계, 비슷한 도구와의 차이를 쉬운 말로.

## ⑤ 출처 `#sources`
두 자료의 링크·라이선스·인용 문구·쓴 판·받은 날짜.

## 사실 · 해석 · 불확실 카드 규칙
- **사실**(자동): 다음 틀로 만든다.
  `{A}와 {B}의 외교 거리는 {처음 구간}에 {값1}, {마지막 구간}에 {값2}로 {커졌다/작아졌다/거의 같았다}. 같은 기간 {A}에게 {B}의 교역 비중은 {비중1}%에서 {비중2}%로 {늘었다/줄었다/거의 같았다}. 출처: Voeten 외 UNGA 이념 위치 점수 {판}, CEPII BACI HS92 {판}.`
- **해석**: `interpretations.json`에 있는 쌍만 {요약, 출처 제목, 링크, 확인 날짜}를 보여 준다. 없으면 "이 쌍에는 아직 검수된 해석이 없습니다."
- **불확실**(공통 목록 + 쌍별 추가):
  - 유엔총회 투표는 외교 관계의 한 면일 뿐이다(동맹·정상회담·제재·여론은 담지 않음).
  - 이념 위치 점수는 한 줄로 줄인 값이라 주제별 입장 차이가 섞여 있다.
  - 교역 비중은 환율·경기·원자재 가격·공급망 이동 같은 다른 요인으로도 바뀐다.
  - 교역 통계는 신고국마다 차이가 있고, BACI는 이를 하나로 맞춘 추정값이다.
  - 두 자료 모두 새 판에서 과거 값이 바뀔 수 있다.

# 디자인

- 디자인 방향은 따로 정한다. `alignment-lens/DESIGN.md`가 있으면 그것을 먼저 읽고 따른다. 없으면 **시안 두 개**를 만들어 비교할 수 있게 보여 주고 내가 고르게 한다.
- 공통 기준: 데이터가 주인공. 장식 효과(빛 번짐, 3D, 과한 그림자)는 쓰지 않는다. 색은 CSS 변수(토큰)로 정하고 다크 모드용 값을 따로 둔다. 두 지표(외교 거리, 교역 비중) 색은 색약 사용자도 구별되게. 글자는 한국어가 잘 읽히는 글꼴.
- 실제 회사 로고, 지어낸 후기, 가짜 사용자 수를 넣지 않는다.

# 만드는 순서 (한 단계씩 끝내고 나에게 보여 준 뒤 다음으로)

0. **자료 확인**: 두 자료의 최신 판, 열 이름, 나라 코드를 확인하고 맞지 않는 나라 목록을 보여 준다.
1. **데이터 스크립트 + 쌍 화면**: `build_data.py`, 두 그래프, 사실 카드, 공통 불확실 카드. 예시 쌍 3개의 값을 원자료에서 손으로 계산한 값과 대조한 표를 보여 준다.
2. **첫 화면, 방법·출처, 한/EN, 다크/라이트, CSV, 배포 설정**.
3. **한 나라 화면**(산점도·슬라이더·표)과 같이 움직인 정도.
4. **해석 카드 자리와 다른 서비스 링크**. 해석 내용은 내가 채운다.

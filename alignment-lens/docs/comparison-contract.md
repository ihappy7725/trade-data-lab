# 직접 대조 도구: 데이터 계약과 검사 규칙

현재 이름 Mirrorline은 임시 유지한다. 기존 서비스 폴더 alignment-lens 안에서만 개발한다.

## 첫 지원 범위

- 국가: 중국 CHN/156, 한국 KOR/410, 미국 USA/842. 숫자 코드는 UN Comtrade 신고국·상대국 코드다.
- 연도: 2017, 2018, 2023. 이는 선택 수집 범위이며 연속 시계열 또는 최신 자료 전체라는 뜻이 아니다.
- 연간 상품 전체(TOTAL), 상대국2=0, customs=C00, 운송수단=0. 월별·HS 세부 품목은 첫 출시 범위가 아니다.
- 공개 API 국가·연도별 응답 9개에서 각 4개 기록을 확인한다. Comtrade 36개와 기존 Census 표에서 보존한 2017년 미·중 참고 2개를 제공한다. 지원하는 값은 화면 선택 목록에서 확인할 수 있다.

## 공통 관측값

`id`, `origin`, `destination`, `reporter`, `partner`, `flow`, `year`, `frequency`, `commodity`, `classification`, `currency`, `unit`, `valuation`, `value`, `publisher`, `retrieved_on`, `edition`, `source_url`, `source_hash`, `reported`, `aggregate`, `original_classification`, `partner_basis`, `trade_system`.

- 실제 교역 방향 origin→destination과 신고국/수출입 방향을 별도로 보존한다.
- value는 소수 문자열, 결측은 null. 원문 수치를 부동소수점으로 반올림해 저장하지 않는다.
- Comtrade 가격은 실제 primaryValue와 일치하는 CIF/FOB 필드를 검사한다. FOB라는 API 필드 이름을 미국 원통계 FAS와 동일 정의라고 주장하지 않는다.
- Census 단위는 원표의 백만 USD 소수 첫째 자리에서 USD로 변환한다. 정밀도가 높아졌다고 주장하지 않는다.
- 상대국 지정 기준 및 집계 체계는 API 응답만으로 확정하지 못하므로 null이다. 알려진 통계 일반론으로 개별 자료의 미확인 메타데이터를 채우지 않는다.

## 검사 결과

각 항목은 match/different/unknown. match는 그 항목이 같다는 뜻이며 전반적 통계 정확성이나 직접 비교의 완전성을 인증하지 않는다.

- 방향, 기간/빈도, 품목 범위, 통화, 단위가 같아야 차액을 계산한다. 같은 기록 중복 및 값 누락도 보류한다.
- 세부 품목에서는 분류 판 일치를 요구한다. 현재 TOTAL에서는 분류 판 차이·미확인을 표시하되 상품 전체 산술 차액은 별도로 제공한다.
- 가격 기준·조회일·원분류 여부의 차이는 그대로 표시한다. 가격 보정이나 원인 기여액을 계산하지 않는다.
- 차액은 B−A다. 기록 순서를 바꾸면 부호가 바뀐다. 무조건 수입−수출이나 무역수지라고 부르지 않는다.

## 조회본과 노트

- 공통 자료의 조회본 식별자는 데이터 내용의 SHA-256이다. 원본 응답별 해시와 URL·조회일도 보존한다. API가 주지 않은 판 번호를 만들지 않는다.
- data/workbench/catalog.json은 현재 목록, snapshots/{식별자}.json은 보존한 불변 자료다. 새 수집 시 이전 조회본은 삭제하지 않는다.
- 노트는 format=trade-comparison-note, schema_version=1, snapshot_id, created_at, memo, observations 두 개를 포함한다. 별도 계산 결과는 불러오지 않고 다시 계산한다.
- 파일 크기, 금액 형식, 국가·방향 일관성, 조회일, 공식 출처 도메인, 해시 형식을 검사한다. 문서 문자열은 HTML로 실행하지 않는다.
- 공식 도메인·해시 형식이 맞아도 진위가 증명되는 것은 아니다. 내장 또는 보존 조회본의 관측값 전체와 일치할 때만 그 일치를 표시한다. 확인할 조회본이 없으면 파일에 보존된 값임을 명시한다.
- 현재 자료와 비교해도 원래 금액·조건·메모는 덮어쓰지 않는다. 이전 값과 최신 내장 값, 차이·조건 변화 여부를 구분한다. 실시간 API 조회라고 표시하지 않는다.
- 로그인·서버 업로드·AI·추적·localStorage 없이 동작한다. 새로고침 시 노트 파일을 다시 여는 것이 정상이다.

조회 날짜가 같아도 원자료의 발표·개정 시점이 같은 것은 아니다. released_on을 별도 필드로 두고 확정된 발표·개정일이 없으면 null/확인 불가로 표시한다. 조회일 일치를 판 일치로 해석하지 않는다.

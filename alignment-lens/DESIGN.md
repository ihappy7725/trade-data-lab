# Mirrorline · 사례 중심 근거 대조

2026-11-19 사용자 요청: 새 기획에 맞춰 사례 하나를 완성하고 서비스의 출발점·존재 이유를 명확히 한다. 이전 PARALLEL 디자인 기록은 docs/parallel-design-archived.md에 보존한다.

- 첫 화면에서 실제 사례의 질문·양국 공식 설명·통계 대조 진입을 제공한다. 지구·선박·브랜드 도입 연출은 새 화면에서 사용하지 않는다.
- 원문을 양쪽에 같은 위계로 배치하되, 다른 지표·문서 시점임을 가까이에 표시한다. 모바일은 순서대로 배치한다.
- 과도한 기업 소개 섹션, 가짜 통계, 후기, 장식용 사진을 넣지 않는다.
- 미색 대신 흰색과 차가운 회색 바탕·명확한 글자 대비, 타이포그래피와 선으로 구성한다. 색은 CSS 변수로 정의하되 이전 고정 컬러키를 유지해야 한다고 간주하지 않는다.
- 두 신고 기록은 청록 실선·갈색 사선 패턴 및 직접 이름표로 구분한다. 양방향 모두 같은 눈금을 사용한다. 어느 국가를 긍정·부정 색으로 평가하지 않는다.
- 정렬·여백·짧은 금액 막대 모션을 사용한다. prefers-reduced-motion이면 모션을 제거한다. 모션 정지 버튼은 다시 넣지 않는다.
- 본문 16px 이상, 출처·조작 글자 14px 이상. 시스템 한국어 글꼴을 사용한다. 외부 폰트를 요청하지 않는다.
- 시스템 테마와 페이지 안 수동 전환을 지원한다. 언어·테마를 저장소에 기록하지 않는다.
- 계산/출처와 편집된 주장, 확인되지 않은 사항을 구분한다. 인과 판정·국가 평가·검수되지 않은 정치적 해석을 넣지 않는다.
- 375px에서 가로 넘침과 표·버튼·양국 비교의 읽기 순서를 실제로 점검한다.

## 2026-11-19 · 직접 만드는 대조 도구로 전환

- 사용자 승인한 방향: 새 대조 만들기 → 비교 조건 점검 → 결과 확인 → 근거 노트 저장·다시 열기.
- 첫 화면의 주요 기능은 국가·방향·기준연도와 지원 기록 선택이다. 나라를 임의로 미리 넣지 않는다. 연도 선택 후 실제 확보한 UN 양측 기록을 제안하며 사용자가 다른 기관 기록으로 바꿀 수 있다.
- 기존 미·중 사례는 mirrorline-case.html에서 예제로 보존하며 새 대조로 돌아오는 링크를 제공한다.
- 기록 A/B를 같은 위계로 보여 주고 정확한 금액·단위·조회일·출처를 가까이에 둔다. 조건은 일치/차이 있음/확인 불가로 나누며 전체 신뢰도 점수는 표시하지 않는다.
- 정식 서비스명은 아직 확정하지 않았으므로 Mirrorline을 유지한다. 폴더·Vercel 프로젝트 이름은 바꾸지 않는다.

# 로컬 구현 검증 · 2026-11-17

- 예시 3쌍 + 고정 시드 무작위 7쌍, 4개 연도, 양방향 원자료 독립 계산: 80건 통과. 빌드 캐시·파서를 재사용하지 않음. 사람이 수행한 손 계산은 아님.
- Spearman 상관: pandas 평균 순위와 Pearson 상관을 사용한 별도 대조 20건 통과.
- 현재 CSV: 30개 연도, 210개 원숫자 대조 통과. 동의 점수와 수출·수입 비중의 화면 표시 열도 포함. 자료 판·출처·결측 상태 명시.
- 231개 나라/지역 JSON의 순위 상관·상대국 집계 범위 배열 길이 확인.
- 화면 금지 문구 0건, 실행 코드의 상위 폴더 경로 0건.
- 브라우저: 쌍↔국가 이동, 정렬, 재생, 연도 조작, 상세 그래프, 한·영, 다크·라이트, 모션 정지·재생 확인.
- 375px 화면에서 첫 화면·쌍 화면·국가 화면 가로 넘침 없음.
- localStorage 접근 시 SecurityError를 발생시키는 실제 검사 화면에서 쌍 화면과 연도 조작 정상, 콘솔 오류 없음.
- 대만 투표 자료 없음, 2024년 투표 자료 없음, 교역 관측값 유지 확인.
- 검수 해석 JSON은 빈 객체 유지. 사용자 확인 Tradeweave 주소 연결.
- 공개 배포·커밋·push는 이 작업에서 수행하지 않음. 전용 Vercel 프로젝트 설정과 실제 배포 검증은 남아 있음.
- 정적 자료 약 141 MB. Vercel Hobby CLI의 100 MB 업로드 제한은 README에 공식 문서와 함께 기록.

# Tradeweave

국가·지역을 검색하면 교역 상대국과 쏠림 정도를 지도 한 장으로 보여 주는 서비스 **Tradeweave**입니다. 별도 프런트엔드 빌드 없이 제공하는 정적 웹앱입니다. HTML·스타일·데이터 및 라우팅·분석 워크스페이스를 역할별 파일로 나누었으며 Vercel에 그대로 배포됩니다.

## 배포되는 것

- `index.html`: 홈 지도·결과 화면의 국가 검색, 실제 사례, 집중도와 CSV, 방법·출처 화면. `#해시`로 전환하며 결과 주소 예시는 `/#see/KOR/export`입니다.
- `data/trade-2024.json`: 나라별 수출·수입 상대국 전체 (CEPII BACI HS22 V202601, 2024년, 상품 전체 합계, 천 미국 달러)
- `data/world-map.json`: 미리 계산한 세계 지도 SVG 경로 (Natural Earth 110m, 정거원통 도법. 110m에 없는 작은 나라는 50m 중심점에 점으로 표시)
- `assets/studio.css`: 화면·컴포넌트·반응형·모션·인쇄 디자인 체계
- `assets/app.js`: 데이터 로딩·검색·라우팅·기존 교역 계산·지도의 상태 갱신
- `assets/analysis.js`: 비중·순위 변화의 순수 계산
- `assets/studio.js`: 지도 카메라·연동 강조·분석 탭·품목 검색·저장·PNG·인쇄
- `data/catalog.json`: 제공 연도·품목·국가명과 데이터 파일 목록
- `data/series/HS22-V202601/`: 2022–2024년의 상품 전체·HS 2단위 산업군 96개·주요 HS 4단위 품목 19개의 자료(총 348개 범위·연도 조합). 2024년 상품 전체는 기존 `trade-2024.json`을 그대로 재사용합니다.
- `assets/tradeweave-mark.svg`: 확정된 W 심벌을 벡터로 정리해 헤더·favicon에 적용. `tradeweave-mark-v2.png`는 원본과 apple-touch-icon으로 유지
- `vercel.json`: 깔끔한 주소 설정

`.vercelignore`로 `materials/`, `scripts/`, `raw/`, `docs/`, `README.md`, `CLAUDE.md`는 배포에서 뺍니다. 원자료 ZIP과 다운로드 조각은 `raw/`에만 보관하며 Git에서도 제외합니다.

## 데이터 다시 만들기

서비스 폴더에서 실행합니다. 연도·품목 자료 집계는 Python 3.11 이상과 curl만 사용합니다.

```bash
python3 scripts/download_baci.py --version 202601 --workers 4
python3 scripts/build_series.py
```

- 공식 ZIP 안의 HS22 2022·2023·2024 원자료를 모두 읽어 각 나라 쌍의 `scripts/product-scopes.json`에 정의한 모든 범위를 집계합니다. 전체 HS 2단위 산업군과 주요 HS 4단위 품목이며, 산업군 표시는 탐색용 요약명입니다. Decimal 합계 후 천 달러 단위로 half-even 반올림하고, 반올림 후 0인 기록은 제외합니다.
- 전체 ZIP 항목을 읽으며 CRC를 검증하고, 원자료 SHA256·행 수·범위별 합계·기존 파일과의 차이를 `raw/series-build-audit.json`에 기록합니다. HTTP 범위 다운로드는 각 응답의 Content-Range와 크기를 확인하고 중단된 조각부터 재개합니다.
- 같은 배포판의 2024년 상품 전체는 기존 파일과 모든 거래액이 일치해야 합니다. 다르면 집계를 중단합니다. 기존 2024 상품 전체를 제외한 347개 자료를 쓴 뒤 마지막에 catalog를 갱신합니다.
- 새 BACI 배포판을 도입할 때는 제공 연도·HS 분류·국가 코드를 확인하고 집계 결과와 기존 값의 차이를 검토합니다. 화면은 catalog의 제공 범위와 메타데이터를 읽습니다.
- 대만은 BACI의 `Other Asia, nes`(코드 490, ISO3 자리 `S19`) 값을 대만으로 표시합니다.

지도를 다시 만들 때는 아래처럼 별도 패키지 폴더를 사용합니다. 경로와 점의 좌표를 같은 정거원통 투영으로 생성합니다. 남극을 제외하며, 작은 나라는 Natural Earth 50m 중심점으로 표시합니다.

```bash
TRADEWEAVE_DIR="$PWD"
npm install --prefix /tmp/tradeweave-map-deps d3-geo@3.1.1 topojson-client@3.1.0 world-atlas@2.0.2
cd /tmp/tradeweave-map-deps
node "$TRADEWEAVE_DIR/scripts/build_map.mjs" "$TRADEWEAVE_DIR/data/trade-2024.json" "$TRADEWEAVE_DIR/data/world-map.json"
```

`build_trade_data.py`는 기존 2024년 상품 전체 파일의 최초 생성 스크립트로 유지합니다(pandas·pycountry 필요). 지도 도법을 바꾸면 `index.html`의 지도 비율·출처 설명·지도 요청의 버전 쿼리도 함께 갱신합니다.

## 배포되지 않는 것 (`materials/`)

기획 단계 결과물 보관용입니다. 사이트에는 올라가지 않고 저장소에만 있습니다. 로컬에서 `materials/hub.html`로 열어 볼 수 있습니다.

| 경로 | 내용 |
|---|---|
| `materials/concentration/` | 쏠림 계산기 (CR1·CR3·CR5·HHI). claude.ai 밖에서는 localStorage에만 저장, Claude 버튼 숨김 |
| `materials/deck/` | 투자자 소개 5장 정적 뷰어 |
| `materials/launch-copy/` | 런칭 문구 |
| `materials/design-system/` | 디자인 시스템 (README·토큰·컴포넌트) |
| `materials/docs/` | 한 장 기획서 (전체 아이디어 목록은 저장소 루트 `docs/`로 이동) |
| `materials/data/` | 월별 예상 방문자 **가상 데이터** (xlsx) |

## 지금 상태

홈 지도와 결과 화면에서 국가·지역을 검색할 수 있습니다. 한국·대한민국·Korea·KOR와 같은 이름을 처리하며, 여러 국가가 검색되면 목록에서 하나를 고르도록 안내합니다. 검색과 선택은 브라우저 안에서 처리합니다.

실제 BACI 값으로 지도, 상위 5개 상대국, 1위·상위 3개·상위 5개 비중과 전체 상대국 HHI를 제공합니다. 홈의 탐색 질문은 한국 수출·베트남 수입 집중도·카타르 수출 데이터로 연결됩니다. `#source`에는 실제 자료의 범위·계산 방법·코드 예외와 원자료 링크가 있습니다.

지도·상위 5개 목록·전체 상대국 표에서 같은 상대국을 선택할 수 있습니다. 표는 한국어·영어·코드 검색과 금액·이름 정렬을 지원합니다. 검색·정렬 후에도 원래 순위·분모·집중도는 전체 자료로 계산합니다. 지도에 표시되지 않는 지역도 전체 표에 포함합니다.

상대국 상세는 같은 거래액을 기준국과 상대국의 전체 수출입액으로 각각 나눈 비중과 두 분모를 보여 줍니다. 반대 방향 교역과 같은 거래를 상대국 기준으로 보는 동작을 제공합니다. 기록이 없는 방향은 `기록 없음`으로 표시합니다.

결과 링크에는 선택한 상대국도 담습니다. 클립보드 사용이 제한되면 직접 복사할 주소를 표시합니다. CSV는 첫 개편의 14개 열 뒤에 상대국 기준 분모·비중·순위를 추가한 17개 열을 유지합니다. 내려받기는 표 검색 상태와 관계없이 전체 상대국을 제공합니다.

관련 서비스는 공개된 Policyline·Trade Digest·Trade News Room으로 연결합니다. 선택한 교역 방향에 대응하는 정책 사례가 있으면 Policyline 상세로 바로 연결합니다. Trade Digest 주소는 사용자가 2026-11-19 알려 준 `https://trade-digest-alpha.vercel.app/`입니다. PARALLEL은 사용자가 구현 전이라고 알려 현재 공개 연결 대상에서 제외했습니다.

### 세 번째 개편: 연도·품목 탐색

홈·결과·국가 검색에서 2022–2024년과 세 가지 품목 범위를 선택합니다. 모든 지도·순위·분모·집중도·상대국 비중·CSV가 선택한 범위를 사용합니다. 전자집적회로는 HS 8542이며 반도체 제조장비 전체를 뜻하지 않습니다. HS 27은 석탄·석유·가스와 그 조제품, 역청질 물질·광물성 왁스·전기에너지 등을 포함합니다.

결과의 연도 비교에는 같은 상대국의 3개 연도 교역액·비중과 전체 상대국 CR5·HHI를 표시합니다. 비교연도를 바꾸거나 연도 카드를 눌러 해당 연도로 이동할 수 있습니다. 비중 차이는 %p, 거래액 증감률은 %입니다. 기록이 없으면 0으로 채우지 않습니다. 금액은 경상 달러 기준으로, 변화의 원인을 이 화면만으로 단정할 수 없습니다. 별도 연도 비교 CSV도 제공합니다.

동일 HS22 배포판에 있는 연도만 사용해 분류·자료 버전이 다른 시계열의 혼합을 피했습니다. 선택연도 자료를 먼저 표시하고 나머지 연도는 뒤에서 불러옵니다. 비교연도 요청에 실패해도 현재 지도·표는 유지하며 실패한 연도만 다시 시도할 수 있습니다. 브라우저 요청 캐시는 최근 12개 스냅샷으로 제한합니다. 새 선택 이후 늦게 도착한 이전 요청은 화면을 덮어쓰지 않습니다.

화면 폭을 넓히고 지도에 은은한 깊이와 그림자를 추가했습니다. 로고·favicon을 공통 적용하고 상단의 소속·기준연도 표시는 정리했습니다. 출처는 지도 하단과 방법·출처에 유지합니다. 지도에 커서를 올리면 나라명·비중·금액·범위를 반투명 툴팁으로 보여 줍니다. 화면 가장자리에서 위치를 보정하며 지도 이탈·스크롤·Escape에 닫힙니다. 터치에서는 기존 선택 상세를 사용합니다. 정거원통 도법은 지도의 양끝을 평행하게 펼치며, 위도·경도를 일정한 간격으로 펼치는 특성을 방법·출처에 설명합니다.

### Atlas Studio 개편

- 큰 제목과 반복 패널을 정리하고 지도·순위·선택 관계·분석 탭을 연결했습니다. 연도·품목 변경 시 같은 SVG 경로를 유지해 색이 전환됩니다. hover와 선택 강조는 독립적이며 표·순위·지도 사이에 연동됩니다. 순위와 표 정렬에는 위치 전환, 상세에는 짧은 등장 모션을 적용했습니다. OS의 동작 줄이기를 CSS·JS에서 존중합니다.
- 모바일 상세는 닫기·Escape·배경 선택으로 닫히는 패널입니다. 키보드 포커스를 패널 안에서 이동하고 닫으면 선택한 컨트롤로 돌아갑니다.
- 지도 확대·축소·초기화·지역 보기와 확대 후 드래그를 제공합니다. 카메라 조작은 데이터와 범례를 변경하지 않습니다.
- 연도 추이·구조 변화·전체 상대국·국가 비교를 탭으로 제공합니다. 추이는 2022–2024년 실제 관측점만 사용하며 결측 구간을 잇지 않습니다. 변화 분석은 두 연도 모두 기록된 상대국의 %p·거래액 증감률·순위를 계산하고, 한 연도만 기록된 경우에는 차이를 계산하지 않습니다.
- 국가 비교는 기준국과 선택한 두 국가를 같은 연도·품목·방향·색 구간으로 보여 줍니다. 비중의 분모는 각 국가의 해당 범위 합계입니다. 같은 국가의 중복 비교는 방지합니다.
- 품목 탐색은 HS 코드·한글 이름 검색을 지원합니다. HS 4단위는 전체 목록이 아닌 선별한 19개 품목입니다. 새로운 범위는 `scripts/product-scopes.json`에 추가하고 집계를 다시 실행합니다.
- ‘분석 저장’은 명시적으로 누른 조건만 이 브라우저의 localStorage에 보관합니다. 이름 변경·복원·삭제 취소를 지원하며 최대 30개를 유지합니다. 저장을 막은 브라우저에서는 실패를 알리고 링크 복사를 안내합니다.
- ‘지도 PNG’는 기본 지도 또는 선택한 국가 비교를 1800px 이미지로 내보냅니다. 수치·연도·품목·분모·범례·출처·라이선스를 포함합니다. 현재 지도 카메라 확대 상태와 관계없이 세계 전체를 담습니다. 인쇄는 기본 분석 또는 현재 국가 비교의 전용 스타일을 사용합니다. 인쇄 창에서 PDF 저장도 가능합니다.
- 기존 전체 상대국·연도 CSV에 더해 변화 분석·국가 비교 CSV를 제공합니다. 모두 현재 범위의 원자료 값을 사용하고 미기록 값은 빈 칸입니다.
- 자료 오류는 재시도할 수 있으며, 기존 화면을 유지한 실패에서는 이전 조건의 자료임을 명시합니다. 늦은 이전 응답은 최신 선택을 덮어쓰지 않습니다.

### 전체 탐색·비교·보고서 확장

- 탭을 바꾸면 이전 구역 경로를 정리합니다. 새로고침·공유·저장 복원에서도 같은 탭을 열고, 이전 버전의 구역·탭 충돌 주소도 복구합니다.
- 구조 변화에서 국가 검색, 증가·감소·유지, 최소 비중 변화, 비교연도, 정렬을 선택합니다. 15개씩 이동하거나 전체를 펼칠 수 있습니다. 미기록 전환은 별도로 표시합니다.
- 국가 비교 아래의 동일 상대국 표에서 세 보고국의 비중·금액·순위를 같은 행으로 비교합니다. 검색·보고국별 정렬·전체 CSV를 지원하며 각 열의 분모는 해당 보고국 전체 교역액입니다.
- 추이 아래에서 상대국 교역액과 기준국 전체 교역액의 증가율을 함께 설명합니다. 두 연도 중 하나가 미기록이면 계산하지 않습니다.
- ‘분석 보고서’는 메모·전체 지도·선택 상대국 추이·숫자 해석·전체 구조 변화·동일 상대국 표·자료 버전과 출처를 하나의 HTML 파일로 저장합니다. 화면 검색·페이지 조건과 관계없이 전체 자료를 포함하며, 오프라인 열람과 브라우저의 인쇄/PDF 저장이 가능합니다.
- 회귀 검증: 서비스 폴더에서 `node scripts/test-workspace.cjs`. 탭·기존 저장 링크 복원, 정확한 국가 코드 검색, 페이지·필터, 실제 자료의 비교 행렬과 결측·숫자 해석을 검사합니다. 브라우저 모션·시각 검증은 별도로 수행합니다.

### 주소 호환

- `#see/KOR/export`, `#see/KOR/import`: 기존 결과 주소
- `#QAT`, `#see/QAT`: 카타르 수출 결과로 정규화
- `#see/TWN/import`: BACI의 S19 대만 수입 결과로 정규화
- `#map`, `#share`: 현재 선택 국가의 지도·집중도로 연결. 최초 진입은 한국 수출
- `#see/VNM/import/concentration`, `#see/QAT/export/sources`: 결과의 집중도·출처 구역으로 바로 이동
- `#see/KOR/export?partner=CHN`: 한국 수출 화면에서 중국을 선택한 상태
- `#see/KOR/export/partner?partner=CHN`: 두 나라 비중 상세로 바로 이동. `partners`는 전체 상대국 표, `related`는 관련 서비스 구역
- 상대국 쿼리도 TWN을 S19로 정규화하며, 잘못된 코드에는 안내와 함께 첫 번째 상대국을 표시합니다.
- `#see/KOR/export?partner=CHN&year=2022&product=8542`: 2022년 전자집적회로 한국→중국. `year`·`product`·`compare`를 공유 주소에 보존합니다. 기본 2024년·상품 전체는 생략합니다.
- `#see/KOR/export/comparison?partner=CHN&product=27&compare=2022`: 연도 비교 구역으로 이동, 2022년과 2024년 HS 27 비교
- `#?year=2023&product=8542`, `#pick?year=2023&product=8542`, `#source?year=2023&product=8542`: 홈·검색·출처에서도 범위 보존
- 지원하지 않는 연도·품목은 안내 후 기본 자료로 복구할 수 있습니다.
- `#see/KOR/export?product=8703&tab=countries&peers=JPN,S19`: 같은 범위의 한국·일본·대만 비교. `tab`은 trends/changes/partners/countries, `peers`는 비교 국가 두 곳입니다.
- `#?country=JPN&flow=import&product=85&year=2023`: 홈 지도 국가·방향까지 복원
- `#pick`: 국가 검색 화면, `#source`: 방법·출처

데이터 출처: CEPII BACI HS22 V202601 (Gaulier & Zignago, 2010), UN Comtrade 기반 · 제공 연도 2022–2024 · Etalab Open Licence 2.0.

설계 결정과 확인 결과는 `docs/decisions.md`에 기록합니다.


### 2026-11-23 연구 흐름 개편

분석 조건에 비교연도를 통합하고 데스크톱에서 고정합니다. 내보내기는 PNG·보고서·인쇄를 묶으며, 선택 관계의 정확한 금액·분모·출처는 펼쳐 봅니다. 국가 비교표는 비중·금액·순위 중 한 지표를 선택해 읽습니다. 작은 화면은 표 내부에서 가로 스크롤하고 상대국 이름 열을 고정합니다.

관측 요약은 상위 5개 쏠림·비중 변화가 큰 상대국·선택 관계의 금액과 비중을 근거 구역과 연결합니다. ‘연도 추이’의 ‘두 시점 비교’를 펼치면 같은 색 구간의 두 지도와 상대국별 양쪽 연도 금액·비중·차이·순위를 봅니다. 화면은 처음 15개를 보여주며 전체 펼치기·검색·정렬·전체 CSV를 제공합니다. 보고서에는 두 지도와 전체 비교 행, 관측 요약도 포함합니다.

‘메모’는 현재 분석 조건에 적용하고 ‘분석 저장’을 누를 때만 브라우저에 보관합니다. 메모·표 필터/정렬·두 시점 보기 상태·자료 버전/해시를 함께 저장하며 이전 URL 저장 항목도 엽니다. 저장 목록에서 JSON 백업/가져오기를 지원합니다. 백업은 조건·메모이며 BACI 원자료 전체 복사본은 아닙니다. 현재 자료 버전과 다르면 경고하고 ‘현재 자료로 다시 분석’을 선택해야 복원합니다. 잘못된 파일은 기존 저장을 변경하지 않습니다.

다른 Trade Data Lab 서비스 링크에는 `tw_source/country/partner/flow/year/compare/product/version` 맥락을 전달하고, 조건·출처·돌아올 주소 복사 및 JSON 저장을 제공합니다. 수신 서비스의 자동 필터 적용을 의미하지 않습니다.

연구 화면은 `assets/research.js`·`research.css`, 백업 검증은 `assets/workspace-state.js`, 순수 기간 계산은 `assets/analysis.js`에 분리했습니다. 서비스 폴더에서 다음 검증을 실행합니다.

```sh
node scripts/test-workspace.cjs
node scripts/test-research.cjs
```

DOM 통합 검증은 별도 jsdom 설치가 필요합니다. 실제 브라우저의 레이아웃·모션 시각 검증을 대체하지 않습니다.

```sh
npm install --prefix /tmp/tradeweave-tests --cache /tmp/tradeweave-npm-cache jsdom@31.0.1
NODE_PATH=/tmp/tradeweave-tests/node_modules node scripts/test-research-dom.cjs
```


### Open Atlas 디자인 · 2026-11-23

사용자 디자인 레퍼런스를 반영해 밝은 쿨 화이트와 안개색 지형, 넓게 펼친 홈 지도·수평 순위 카드·두 열 탐색 질문으로 정비했습니다. 분석 화면·표·상세·대화상자도 같은 시각 체계를 사용합니다. 지도 도법·5개 비중 구간·BACI 수치는 유지합니다.

홈은 기본 1위 상대국, 결과는 선택 상대국의 실제 교역 관계에 핀·연결선·수치 라벨을 표시합니다. 가리키기/초점은 임시 미리보기이며 분석 선택값을 바꾸지 않습니다. ‘교역 관계 표시’로 끄고 켤 수 있습니다. 선은 운송 경로가 아니며 핀은 지도상의 대표 위치입니다. 미기록이나 대표점 없는 지역에는 선을 만들지 않습니다. 작은 화면에서는 SVG 라벨 대신 HTML 관계 정보/상세를 사용합니다.

대표점은 `scripts/build_map.mjs`에서 기존 지도와 같은 투영으로 재생성합니다. `assets/atlas-model.js`는 관계선 기하, `atlas.js`는 시각 상호작용, `atlas.css`는 레퍼런스를 반영한 시각 체계입니다. `node scripts/test-atlas.cjs`로 대표점·방향·라벨 경계를 추가 검증합니다. 실제 브라우저의 전체 화면/모션/모바일 시각 검수는 별도로 필요합니다.

### 한영 지원·분석 화면 정비 · 2026-11-24

큰 슬로건과 장식 영어 표제를 제거했습니다. 제목은 실제 데이터 범위를 표시하며, 변화 요약은 지도 아래에서 펼쳐 봅니다. 선택한 상대국과 가리킨 상대국을 구분하고 ‘선택 관계 확대’로 두 국가가 함께 보이게 합니다. 데이터와 선택 조건은 변하지 않습니다.

한국어/English 버튼은 메뉴·설명·국가·품목·단위·접근성/오류 안내·보고서·CSV까지 전환합니다. 선택한 언어는 브라우저에 보관하며 링크에는 `lang=ko` 또는 `lang=en`을 포함합니다. 국가·연도·품목·필터·메모는 유지하고, 사용자 메모와 저장 이름은 번역하지 않습니다. 영어 금액은 US$ compact, 비중 차이는 pp로 표시하며 정확한 금액과 CSV의 천 달러 단위는 유지합니다.

문구 템플릿과 영문 HS22 탐색명은 `assets/locales/en.js`, 언어 처리와 정적 바인딩은 `assets/i18n.js`에 있습니다. 새 UI 문구는 `i18nText(key, values)`와 동일한 변수 자리를 갖춘 영문 사전을 함께 추가합니다. 새 품목 범위를 추가할 때도 영문 라벨·설명을 제공해야 합니다. 이름과 검색 인덱스는 한국어·영어를 모두 지원합니다. 원자료 수치의 언어별 복사본은 만들지 않습니다.

디자인 토큰은 `assets/tokens.css` 한 곳에서 정의하고, 밀도·언어 배치는 `assets/layout.css`에서 관리합니다. 추가 검증:

```sh
node scripts/test-i18n-catalog.cjs
NODE_PATH=/tmp/tradeweave-tests/node_modules node scripts/test-i18n.cjs
```

다음 기능 단계는 HS 2단위 산업별 구성·변화 기여 분석입니다. 이번 배포는 문구·한영 지원과 분석 화면 기반 정비에 해당합니다.

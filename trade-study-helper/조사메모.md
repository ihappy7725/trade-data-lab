# LangGraph 조사 메모

> 출처: DeepWiki(저장소를 AI가 정리한 문서)의 답변.
> **주의:** 아래 내용은 원본 파일을 직접 열어 확인한 것이 아닙니다. 항목별 확인 여부를 함께 적어 두었습니다.

## ① 노드, 엣지, 상태 (비전공자용 설명)

- **노드(node)**: 실제 일을 하는 한 단계입니다. 예를 들어 "AI 모델에게 질문하기", "도구 실행하기"가 각각 하나의 노드입니다. 할 일 목록의 항목 하나라고 생각하면 됩니다.
- **엣지(edge)**: 한 단계가 끝난 뒤 다음에 어디로 갈지를 정하는 연결선입니다. 순서도의 화살표와 같습니다.
- **상태(state)**: 모든 단계가 함께 읽고 쓰는 공유 메모장입니다. 노드는 이 메모장을 읽고, 자기 작업 결과를 적어 넣습니다.

**참고 문서 (DeepWiki 답변 기준)**
- 답변이 언급한 페이지: "Graph API overview", "Thinking in LangGraph"
- 위키 섹션: "Core Execution System" (3번 항목)
- 확인 결과: **두 문서 모두 실제로 있습니다.** `docs/llms.txt` 목차에 "Graph API overview"(graph-api.md)와 "Thinking in LangGraph"(thinking-in-langgraph.md)가 나옵니다. "Core Execution System"은 DeepWiki의 위키 목차 이름이라 저장소 파일로는 확인하지 않았습니다.

## ② 가장 간단한 그래프 예시가 있는 문서

- 확실한 문서 이름은 찾지 못했습니다.
- DeepWiki는 `libs/langgraph/langgraph/graph/state.py` 파일의 `StateGraph` 설명문(docstring)에 노드 하나짜리 간단한 예시가 있다고 답했습니다.
- 별도의 문서나 노트북은 가리키지 않았습니다.
- 확인 결과: **예시가 있습니다.** `StateGraph` 설명문의 `Example:` 부분(약 158–196줄)에 있습니다.
- 다만 "가장 간단한" 예시는 아닙니다. 노드가 `A` 하나뿐이지만, 상태 합치기 함수(reducer)와 실행 옵션(context)까지 함께 나와서 입문자에게는 조금 복잡합니다.

## ③ RAG(문서 검색 후 답변) 예시가 있는 문서

- 문서 제목: "Build a custom RAG agent with LangGraph"
- 경로: `agentic-rag.md`
- 링크: https://docs.langchain.com/oss/python/langgraph/agentic-rag.md
- 확인 결과: **있습니다.** 링크를 열어 본문을 읽었습니다. 튜토리얼은 문서를 가져와 나누고 색인(검색 가능하게 저장)한 뒤, 에이전트가 필요할 때만 검색 도구를 쓰도록 LangGraph로 만드는 흐름입니다. 검색이 필요 없으면 바로 답하는 분기도 포함됩니다.
- 이 튜토리얼은 `OPENAI_API_KEY`를 쓰는 OpenAI 모델을 사용하고, LangSmith 추적 설정도 안내합니다. 수업 과제에서는 OpenAI 하나만 쓰는 규칙이 있으므로 LangSmith 설정은 빼고 따라 해도 됩니다.

# Tradeweave studio design

쿨 화이트·블루를 기반으로 한 지도 중심 분석 워크스페이스. 단일 밝은 테마. 가벼운 헤더, 조건 도구막대, 지도와 순위·상대국 패널, 탭형 분석 영역으로 구성한다.

- 숫자는 tabular-nums, 제목은 세리프를 제한적으로 사용한다.
- 강조는 선택한 국가와 관계에 집중한다. 파랑=상대국 비중, 황토=기준국. 상승·하락 색은 변화 표시에서만 사용한다.
- hover 140ms, 패널 240ms, 데이터·막대 320ms. 실제 값은 즉시 표시하며 카운팅 효과로 가짜 중간 수치를 만들지 않는다.
- 지도는 정거원통 도법과 고정 범례를 유지한다. zoom/pan은 탐색용이며 수치를 바꾸지 않는다.
- 모바일 상세는 닫을 수 있는 bottom sheet. 표·순위 버튼과 키보드로 동일한 상대국을 선택할 수 있다.
- prefers-reduced-motion을 CSS·JS 양쪽에서 존중한다.
- HTML은 구조, assets/app.js는 데이터·라우팅·기존 계산, assets/studio.js는 탐색·비교·저장·내보내기, assets/studio.css는 시각 체계를 담당한다.

## 2026-11-23 연구 흐름 정비

- 분석 조건은 데스크톱에서 sticky 도구막대로 유지하며 국가·품목·선택연도·비교연도·방향을 함께 읽는다. 모바일에서는 화면을 가리지 않도록 일반 흐름에 둔다.
- 주요 활용 동작은 저장·메모·공유와 내보내기로 구분한다. PNG·보고서·인쇄는 내보내기에 묶는다.
- 선택 관계는 금액·기준국 내 비중·비교연도 차이를 먼저 보여주며 정확한 금액·양쪽 분모·출처는 펼친다. 오류 안내는 펼침 여부와 관계없이 노출한다.
- 요약은 관측값과 산술 관계만 설명하며 근거 구역으로 연결한다. 각 연도의 CR5는 해당 연도의 상위 5개를 각각 합산한 값임을 명시한다.
- 두 시점 비교는 별도로 펼쳐 보며 지도 색 구간은 동일하게 고정하고 연도·분모를 각각 표시한다. 금액은 경상 달러, 미기록 차이는 계산하지 않는다.
- 비교표의 비중·금액·순위는 전환해서 읽고, 비중만 공통 색 구간으로 채색한다. 상대국 이름 열을 고정하며 표 내부에서 가로 스크롤한다.
- 비교표 정렬에는 실제 행의 위치 전환만 적용한다. 지도·표의 hover와 선택을 연결하며 reduced-motion에서는 이동 효과를 제거한다.
- 최소 보조 글자와 모바일 조작 크기를 보강한다. 새 연구 기능은 assets/research.js·research.css, 백업 스키마는 assets/workspace-state.js로 분리한다.


## 2026-11-23 Open Atlas · 사용자 레퍼런스 반영

- 레퍼런스의 옅은 배경·큰 지도·수평적인 조작부·가벼운 카드와 여백을 적용한다. 출처·연도는 지도 설명과 하단에 유지한다.
- 홈은 중앙 제목, 떠 있는 조건 도구막대, 경계가 약한 전체 너비 지도, 하단 수평 순위 카드, 두 열 탐색 질문으로 구성한다.
- 쿨 화이트·안개색 지형·단계별 블루를 쓰고 기준국은 황토색으로 유지한다. 정거원통 도법·다섯 비중 구간·숫자는 변경하지 않는다.
- 핀은 기존 지도와 같은 투영의 국가별 대표점이다. 연결선은 한 개의 실제 기록된 교역 관계를 설명하는 도식이며 실제 운송 경로·항로가 아님을 표시한다. 지도에 없는 지역의 위치는 추정하지 않는다.
- 가리키기·키보드 초점은 미리보기만 바꾸고 선택 조건을 변경하지 않는다. 이탈하면 홈은 1위 상대국, 결과는 선택 상대국으로 돌아간다. 관계 표시를 끄는 동작을 제공한다.
- 관계 레이어는 240ms 투명도 전환으로 나타난다. 확대 시 수치 라벨을 숨기고, 작은 화면에서는 SVG 라벨 대신 HTML 관계 정보와 기존 상세 패널을 사용한다. reduced-motion에서는 효과를 생략한다.
- 홈·분석·비교·저장 창은 동일한 색·반경·그림자·타이포그래피를 공유한다. 레퍼런스 시각 체계는 assets/atlas.css·atlas.js, 관계선 기하는 assets/atlas-model.js로 분리한다.

## 2026-11-24 문구·언어·정보 밀도

- 사용자 요청에 따라 큰 슬로건과 장식용 영어 표제를 제거한다. 제목은 국가·품목·비교·출처처럼 실제 내용과 동작을 설명한다.
- 한국어/English 전환을 실제 UI 기능으로 제공한다. 메뉴·설명·국가·품목·단위·오류·접근성 라벨·보고서·CSV를 같은 언어로 표시하며, 사용자가 쓴 메모와 저장 이름은 번역하지 않는다.
- 언어를 바꿔도 국가·상대국·연도·품목·필터·메모·계산값은 유지한다. 명시적 언어 선택만 브라우저에 저장하고 공유 주소의 lang=ko/en으로 언어를 재현한다.
- 지도와 선택 관계를 먼저 보여주며 변화 요약은 지도 아래 접어서 둔다. 선택 상대국과 미리보기 상대국은 서로 다른 상태 칩으로 표시한다.
- ‘선택 관계 확대’는 두 대표점을 함께 보도록 카메라만 이동한다. 자동 hover로 확대하지 않으며 데이터·도법·색 구간·선택 상태를 바꾸지 않는다.
- 색·글꼴·간격 토큰은 assets/tokens.css 한 곳에서 정의한다. 언어와 밀도/상태 배치는 assets/layout.css에 둔다. 기존 세 스타일 파일의 중복 :root 선언은 제거한다.
- 영문 품목명은 짧은 HS22 탐색명이며 법적 품목 해석을 대체하지 않는다. HS 4단위는 기존과 같이 19개 선별 범위임을 양 언어에 명시한다.

## 2026-11-26 산업 구성·증감 기여

- 산업 구성은 지도 품목 범위와 독립된 HS 2단위 96개 전체의 분석 탭이다. 상품 전체를 분모로 쓰는 사실을 조건·설명·보고서에 명시한다.
- 국가 전체 또는 선택 상대국과의 교역을 전환한다. 상대국 분석의 국가 전체 산업 비중은 비교용 기준이며 상대국 구성의 분모와 혼합하지 않는다.
- 산업 변화의 기여는 비교연도 상품 전체 총액 대비 %p다. 순증감액으로 나누지 않는다. 한쪽 연도 미기록은 빈 값으로 유지하고 신규·중단 거래로 단정하지 않는다.
- 선택연도 금액·증가 기여·감소 기여·코드순과 양 언어 검색을 제공한다. 상위 막대는 검색·정렬 결과의 앞 10개를 표시하고 전체 표는 내부 스크롤과 고정 산업 열을 사용한다.
- 막대는 비중 파랑, 변화 상승·하락만 청록·갈색으로 표시한다. 320ms 표시 전환은 reduced-motion에서 생략한다.
- CSV와 HTML 보고서는 필터와 관계없이 전체 96개 산업을 포함한다. 산업을 누르면 해당 HS 2단위 상대국 지도로 이동한다.

# Policyline DESIGN — 제도와 선 (밤 · 입체)

작성일: 2026-11-13 · 기준 시안: `drafts/direction-2c-3d.html`
화면을 만들 때 이 파일과 `PLAN.md`를 먼저 읽는다.

## 1. 방향
- 스타일: **제도와 선 (밤 · 입체).** 짙은 남색 공간 위에 떠 있는 패널과, 그 위에 그어진 주홍색 발표일 선
- 레퍼런스: findyourbeacon.app 의 남색 바탕 · 모눈 · 가는 명조 큰 제목 · 흰 버튼 구성만 참고한다. 로고·문구·이름은 쓰지 않는다.
- 이유: 정책 공부하는 사람이 보는 것은 결국 "발표일 선 하나와 그 앞뒤 교역량"이다. 기억에 남을 요소는 주홍색 선 한 곳에만 쓰고, 나머지는 차분한 입체감으로 정돈한다.
- 입체감을 내는 방법:
  - 첫 화면 바닥에 원근감 있는 모눈 평면 (아래로 갈수록 흐려짐)
  - 카드·패널: 위쪽 1px 하이라이트 + 겹겹의 그림자로 떠 있게
  - 버튼: 아래쪽에 두께(단단한 그림자)가 있고, 누르면 실제로 내려감
  - 필터·언어 토글: 안쪽으로 파인 홈
  - 첫 화면 오른쪽: 최근 정책 3건 카드를 비스듬히 겹쳐 쌓기

## 2. 첫 화면과 페이지 구성
| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 위쪽 줄 | 로고(주홍 세로선 + POLICYLINE), 메뉴 4개, 한/EN 토글 |
| 2 | 첫 화면 | 왼쪽: 제목 · 설명 · [분석할 정책 선택하기] · ✔ 신뢰 지표 2개 / 오른쪽: 최근 정책 3건 입체 카드 |
| 3 | 분석할 정책 고르기 | 관세 / 수출통제 필터, 정책 5건 목록 (날짜 옆 주홍 발표일 선, 데이터가 없으면 "데이터 준비 중" 상태 한 줄) |
| 4 | 정책 하나를 고르면 보는 것 | 정책 화면 한 장의 구조도(점선 도면) + 오른쪽 설명 3줄 |
| 5 | 숫자를 읽을 때 주의할 점 | 구분선 위 글 4개 (패널 없음) |
| 6 | 과제와 글에 그대로 쓰기 | 파인 인용 상자 + 복사 · CSV 버튼 (바깥 패널 없음) |
| 7 | 출처와 방법 | 선만 있는 표 (패널 없음) |

- 떠 있는 패널(그라데이션 면 + 그림자)은 **정책 목록 행과 첫 화면 카드에만** 쓴다. 나머지 섹션은 구분선·점선·파인 홈으로 구분해 섹션마다 모양이 다르게 보이게 한다.
- 데이터가 없는 정책에 빈 그래프 틀을 반복해 두지 않는다. 상태는 행 안 한 줄로만 알린다.

- 단 하나의 행동: **분석할 정책 선택하기.** 첫 화면에서 흰 버튼이 가장 먼저 보인다.
- 첫 화면 문구 (한국어):
  - 제목: 정책 발표 전후 12개월, / 교역량의 객관적 변화 (뒷줄은 회색)
  - 설명: 관세와 수출통제 등 주요 정책 시점을 기점으로 달라진 월별 교역 데이터를 나란히 비교합니다. 원인을 단정 짓지 않고, 같은 시기에 일어난 시장의 실제 변화만 제공합니다.
  - 신뢰 지표: ✔ 로그인 없이 즉시 확인 ✔ 투명한 출처 표기
- 첫 화면에는 예시 그래프를 두지 않는다. 시간축(연도 위 발표일 선) 패널도 쓰지 않는다.

## 3. 언어 (한/EN)
- 모든 문구는 한 곳(I18N 사전)에 한국어·영어 짝으로 둔다. 화면 코드에 문구를 직접 쓰지 않는다.
- 전환하면 `<html lang>`, 정책 이름, 날짜 형식이 함께 바뀐다. 한국어 `2024.07.04` / 영어 `Jul 4, 2024`
- 고른 언어는 브라우저에 기억하되, 기억이 막혀 있어도 한국어로 정상 표시한다.

## 4. 글꼴 짝
- 제목: **Noto Serif KR** 300·400 (가는 명조)
- 본문·숫자·버튼: **IBM Plex Sans KR** 400·500·600, 숫자는 `tabular-nums`
- 둘 다 Google Fonts, 한글·영문 모두 지원
- 한글은 이탤릭 대신 색(흰색 → 회색)으로 강조를 나눈다. `word-break: keep-all`

그림자 토큰
- `--shadow-1`: 위쪽 하이라이트 + 2px·8px 그림자 (기본 카드)
- `--shadow-2`: 위쪽 하이라이트 + 4px·16px·32px 그림자 (떠오른 카드, 패널)
- `--shadow-inset`: 안쪽 그림자 (파인 홈: 필터·토글·아이콘 칸·인용 상자)
- `--shadow-btn` / `--shadow-btn-small` / `--shadow-btn-pressed`: 버튼 두께와 눌린 상태
- `--glow-accent`: 주홍 선의 은은한 빛 (로고 선, 카드의 발표일 선)
- `--color-glow`: 첫 화면 바닥 위 푸른 빛 번짐
- `--glow-brand`: "분석할 정책 선택하기" 버튼 hover 때만 쓰는 빛 테두리
- `--color-sheen`: 같은 버튼을 페이지 열고 1.4초 뒤 한 번 훑고 지나가는 빛줄기

움직임 토큰
- `--dur-enter` .22s (ease-out-quint) · `--dur-exit` .14s (ease-in) · `--dur-press` .08s

## 6. 간격 · 크기
- 간격은 8px 단위: 8 · 16 · 24 · 32 · 48 · 64 · 96 (`--space-1` ~ `--space-12`)
- 바닥 모눈 80px
- 제목은 본문보다 최소 2.4배 (본문 16px, 첫 화면 제목 38~66px, 섹션 제목 28~40px)
- 한 줄 길이는 32~40자 안쪽
- 모서리: 카드·패널 12px, 버튼 10px, 필터·토글 완전히 둥글게
- 버튼 높이: 주요 52px, 작은 버튼 40px

## 7. 움직임
- 무엇이 움직이나
  - 페이지를 열 때 한 번: 첫 화면 정책 카드 3장이 차례로 떠오름 (0.7초, 0.12초 간격)
  - 버튼: hover 때 2px 위로, 누르면 4px 아래로 내려가며 두께가 사라짐
  - 목록 행: hover 때 4px 떠오르며 그림자가 깊어짐
  - 인용 복사 알림: 나타날 때 0.32초, 사라질 때 0.14초
- 규칙: `transform` · `opacity`만 / 퇴장·누름(0.08~0.14초)이 등장(0.3~0.7초)보다 빠르게 / '모션 줄이기' 설정이면 전부 끔
- 섹션마다 아래에서 떠오르는 등장 효과는 쓰지 않는다

## 8. 상태
| 상태 | 주요 버튼 | 목록 행 | 필터 · 언어 토글 |
|---|---|---|---|
| 기본 | 흰 면 + 아래 4px 두께 | 떠 있는 카드 (`--shadow-1`) | 파인 홈 안의 글자 |
| hover | 2px 위로 | 4px 위로, `--shadow-2`, "발표 전후 보기" 밑줄 | 글자 밝아짐 |

| disabled | 투명도 40%, 커서 금지, 움직임 없음 | (해당 없음) | (해당 없음) |

## 9. 하지 않을 것
- 보라 그라데이션, 장식용 그라데이션, 시스템 기본 글꼴
- 주홍색(`--color-accent`)을 발표일 선과 "발표 전후 보기" 말고 다른 곳에 쓰기
- 글자가 흐려질 만큼 크게 기울이기 (5° 넘게), 휴대폰에서 기울인 요소가 화면 밖으로 넘치기
- 첫 화면 예시 그래프, 연도 시간축 패널
- 지어낸 후기, 가짜 사용자 수, 실제 회사·정부 로고
- 출처·기간 없는 숫자. 가상 데이터는 화면과 파일 모두에 "가상" 표시
- "이 정책 때문에 줄었다" 같은 원인 단정 문구
- 모든 제목 위의 영문 대문자 작은 라벨, 버튼 글자 끝의 화살표
- 새 색 값을 화면 코드에 직접 쓰기 (이름표만 사용)
- 회원가입, 뉴스레터, 개인정보를 받는 입력칸

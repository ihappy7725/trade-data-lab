# Trade Digest DESIGN

최종 수정: 2026-11-16 · 기준 시안: [`drafts/design-system.html`](drafts/design-system.html)
화면을 만들 때 이 파일과 `PLAN.md`를 먼저 읽는다. 값이 다르면 **시안의 CSS가 기준**이다.

## 1. 방향
- 키워드: **world · trade · 서재.** 첫 화면은 밤의 딥그린 위에 보고서 표지가 펼쳐진 서가다. 장식은 무난하게, 주인공은 **보고서 표지**.
- 첫 화면 구도는 [melius.com](https://www.melius.com/)을 따른다: 메뉴 줄, 가운데 큰 제목, 양옆으로 갈수록 커지고 꺾이는 오목한 패널 벽, 버튼 둘. Melius 로고 · 문구 · 사진 · 글꼴 파일은 쓰지 않는다.
- 우리 것으로 바꾼 것
  - 패널은 모두 **A4 보고서 표지**다.
  - 뒤에 천천히 도는 **지구본**이 조용하게 깔린다. 대륙과 교역 항로가 보이지만 평평하고 옅다.
  - 설명은 제목 바로 아래 작게.
- 첫 화면 아래(보고서 영역, 내 PDF)는 **서재 종이 바탕**이다.
- 쓰지 않는 것: 주황, 노랑, 빛 번짐(glow), 표지 반사 · 광택, 대륙 입체 효과, 어두운 테마. 언어는 **한 / EN 전환**만 있다.

## 3. 글자
- 제목 `Trade Digest`와 메뉴 줄 로고: **General Sans 600** (Indian Type Foundry, Fontshare 무료 제공). 제목 `clamp(52px, 8.2vw, 132px)`, 자간 -0.055em. 언어와 상관없이 영문 그대로.
- 표지 제목 · 보고서 제목: Hahmlet 300/400. 표지 연도 · `내 PDF 요약` 섹션 제목: Newsreader 400.
- 나머지 전부: Pretendard. 한국어는 `word-break: keep-all`.

## 4. 첫 화면 자리 (화면 폭 W 기준, 메뉴 줄 61px 아래부터)
| 무엇 | 위치 |
|---|---|
| 제목 | 0.046W |
| 두 줄 설명 | 제목 바로 아래 14px, 13–17px 글자 |
| 표지 벽 가운데 | 0.27W |
| 버튼 두 개 | 0.41W |
| 첫 화면 높이 | `max(700px, 64vw)`, 최대 1040px |

표지 벽은 11장이다. 가운데 1장과 양옆 5장씩이고, **모든 표지는 A4 비율(1:1.414)로 같다.** 가운데가 가장 작고 바깥으로 갈수록 크고 많이 꺾인다.

| 가운데에서 | x | 높이 (폭 = 높이 ÷ 1.414) | 꺾임 |
|---|---|---|---|
| 0 | 0 | .110 | 0° |
| 1 | ±.079 | .115 | 8° |
| 2 | ±.164 | .130 | 16° |
| 3 | ±.258 | .155 | 24° |
| 4 | ±.365 | .190 | 32° |
| 5 | ±.488 | .240 | 39° |

- x는 꺾인 뒤 보이는 폭(`폭 × cos(꺾임)`)을 더해 옆 표지와 맞닿게 계산했다.
- 바깥 표지일수록 앞에 놓는다. 맨 바깥 표지는 화면 밖으로 조금 잘려도 된다.
- 표지 그림자는 하나만: `0 18px 40px -18px rgba(0,0,0,.6)`.

## 5. 지구본
- d3-geo 정사영으로 캔버스에 그린다 (world-atlas 110m 육지 지도, jsDelivr에서 불러옴). 인터넷이 안 되면 지구본 없이 나머지가 보인다.
- 구: 거의 평평한 딥그린 (`#183A2D` → `#12291F`). 경위선 아주 옅게.
- 대륙: 평평한 옅은 면 `rgba(236,244,238,.12)` + 옅은 점 질감. 입체 효과 · 그림자 없음.
- 항로 12개: 옅은 흰 선 위로 흰 빛줄기(45%)가 항구에서 항구로 흐른다. 항로는 **예시 그림**이며 교역량을 뜻하지 않는다.
- 캔버스 85%, 제목 뒤는 어둡게 눌러 글자를 잘 읽히게 한다. 첫 화면이 화면 밖으로 나가면 멈춘다.
- 첫 화면 아래쪽 240–380px에 걸쳐 종이색으로 천천히 바뀐다 (투명도 10단계). 점 격자는 화면에 고정해 이음새가 보이지 않게 한다.

## 6. 모션
- **지구본**: 1초에 4°씩 돈다.
- **펼침**: 표지 11장이 가운데에 작게(0.22배) 모여 있다가 제자리로 펼쳐진다. 가운데부터 바깥으로 70ms씩 늦게, 1500ms, `cubic-bezier(.16,1,.3,1)`.
- **표지에 마우스**: 1.04배. **표지 고르기**: 흰 테두리, 나머지는 어둡게. 보고서 영역으로 부드럽게 내려간다.
- **탭 · 펼침 상자**: 380ms / 260ms 위로 살짝 올라오며 나타난다.
- **동작 줄이기** 설정이면 지구본은 멈춘 한 장면, 표지는 펼친 상태로 보여 준다.

## 7. 기능 (눌러 보며 익히기)
| 누르는 것 | 일어나는 일 |
|---|---|
| 표지 | 보고서 영역이 열린다 (머리: 기관 · 연도 · 제목 · 검수 배지 · 쪽수, `원문 PDF` `요약 복사`) |
| `보고서 열어 보기` | 가운데 표지를 연다 |
| 탭 `한 장 요약` / `한계 점검표` / `다른 기관은? 준비 중` | 내용이 바뀐다 |
| 쪽수 버튼 `p. 7 ✓` | 아래에 `쪽수 확인됨 · 원문 구절`이 펼쳐진다. `!`이면 `확인 못 함` 안내 |
| `데이터로 보기 →` | Policyline 연결 안내와 `열기 →` |
| 점선 밑줄 용어 | 쉬운 말 풀이 |
| `내 PDF 요약` | 아래 올리기 상자로 이동. 끌어다 놓기 · 고르기 |
| `EN` / `한국어` | 화면 전체 언어 전환 (브라우저에 기억) |

## 8. 반응형 (760px 이하)
- 메뉴 줄: 로고 + 언어 버튼만.
- 제목 · 설명 · 표지 벽 · 버튼이 위에서 아래로 차례로 흐른다.
- 표지는 1.9배 크게 하고 바깥 표지는 화면 밖으로. 표지 안 기관명은 숨기고 `가상` 표시는 남긴다.
- 요약 세 칸 → 한 칸.

## 9. 지켜야 할 것
- 실제 요약을 넣기 전까지 표지 · 기관 · 문장은 모두 가상이다. 표지마다 `가상` 표시, 보고서 영역에 `가상` 배지.
- 실제 보고서 표지 이미지를 쓸지는 기관별 이용 조건을 확인한 뒤 정한다. 그전까지는 직접 만든 글자 표지를 쓴다.
- 이용자 수, 후기, 기관 로고는 넣지 않는다.

# Trade Data Lab 아이디어 정리

최종 수정: 2026-11-17 · 작성자: 정주연

데이터, 무역, 국제정치경제, 국제정책, 글로벌 이슈를 다루는 서비스를 장기적으로 하나씩 만드는 프로젝트의 아이디어 기록이다.
한 번에 하나씩 완성한다. 서비스별 상세 기획서는 각 서비스 폴더 안에 둔다.

## 목적
- 데이터로 무역·정책 질문을 다뤄 본 경험을 쌓는다.
- 정책대학원(Columbia SIPA MPA) 지원을 가정하고, 지원서와 포트폴리오에서 설명할 수 있는 결과물을 만든다.

## 1. 아이디어가 나온 과정

### 1차 추천 (무역 · 취업 · 관심사 기준) — 채택 안 함
| # | 아이디어 | 한 줄 설명 | 결과 |
|---|---|---|---|
| 1 | 수출통제 첫 점검 도우미 | 품목·수출국을 넣으면 확인할 규정과 공식 출처 링크를 체크리스트로 | 보류 |
| 2 | 바이어 메일 톤 점검기 | 영어·중국어 메일 초안의 무례함·모호함 점검 | 보류 |
| 3 | 채용공고 해석기 | 해외영업·포워딩 공고를 실제 업무·필요 역량으로 풀이 | 보류 |
| 4 | 동아시아 공급망 주간 브리핑 | 공식 발표·기사를 쉬운 말로 요약, 사실/해석 분리 | **2차로 확장** |
| 5 | 수출 서류 대조기 | 인보이스·패킹리스트 불일치 찾기 | 기존 프로젝트(export-doc-workspace)와 겹쳐 제외 |

4번을 고르면서 방향을 바꿈: **중국·공급망에 한정하지 않고, 데이터 / 무역 / 국제정치경제 / 국제정책 / 글로벌에 초점**, SIPA MPA 지원에 어울리는 탐구 아이디어로.

### 2차 추천 (데이터 · 국제정책 기준) — 5개 모두 채택
| # | 아이디어 | 한 줄 설명 | 쓰는 데이터 (예시) | 지원서에서 보여 줄 수 있는 것 | 내 메모 |
|---|---|---|---|---|---|
| 1 | 정책 발표 → 무역 변화 추적기 | 관세·제재·수출통제 발표일 전후로 해당 품목 교역량이 어떻게 달라졌는지 그래프로 | UN Comtrade, 각국 관보·정부 발표 | 정책 효과를 데이터로 따져 보는 사고방식 | |
| 2 | 글로벌 정책 브리핑 (사실·해석 분리형) | 통상·국제정책 뉴스를 "공식 확인된 사실 / 언론 해석 / 아직 불확실한 것"으로 나눠 요약 | 정부·국제기구 발표, 기사 링크 | 정보를 비판적으로 읽고 정리하는 능력 | |
| 3 | 국가별 무역 의존도 지도 | 한 나라를 고르면 주요 수출입 상대국과 쏠림 정도를 시각화 | UN Comtrade, WTO 통계 (실제 구현: CEPII BACI) | 경제안보 질문을 지표로 바꾸는 능력 | Good → 첫 번째로 진행 |
| 4 | 보고서 쉬운 말 요약기 | WTO·IMF·OECD·World Bank 보고서의 핵심 주장, 근거 데이터, 한계를 한 장으로 | 공개 보고서 PDF | 정책 문서를 읽고 쟁점을 뽑는 능력 | KITA·KOTRA 보고서까지 확장 |
| 5 | 이슈 하나 깊게 파는 데이터 노트 | 매달 질문 하나를 정해 데이터와 출처로 답하는 공개 분석 노트 | 질문마다 다름 | 연구 질문을 세우고 끝까지 답하는 과정 | AX 교육 KITA 보고서 스터디의 연장선이라 좋음 |

당시 추천 순서는 1 → 3 → 5였다. 2·4번은 비슷한 도구가 많아 차별점 설명이 어렵다는 이유였다. 최종 선택은 "5개 모두 하나씩 해 보기, 첫 번째는 3번".

## 2. 기존 사이트 Docklab(무역 뉴스 공부방)과의 관계
- 주소: https://trade-news-room.vercel.app/
- 2026-11-16부터 이 저장소의 `trade-news-room/` 폴더에서 관리 (원래 별도 저장소 `trade-news-room`)
- 내용: 실제 뉴스를 읽고, 그래프를 조작하고, 퀴즈·용어로 무역 개념을 공부하는 학습 사이트
- 메뉴: 무역 맵, 실시간 뉴스, 학습실, 내 기록, 용어 사전
- 없는 것: 국가별 대시보드, 정식 브리핑 보고서

| # | 아이디어 | Docklab과 겹침 | 판단 |
|---|---|---|---|
| 1 | 정책·무역 변화 추적기 | 없음 | 별도 서비스 |
| 2 | 글로벌 정책 브리핑 | 많이 겹침 (뉴스 요약 기능이 이미 있음) | **Docklab에 합치기**: 3칸 브리핑 추가 |
| 3 | 국가별 무역 의존도 지도 | 없음 (한국 수출입 그래프 하나뿐) | 별도 서비스 |
| 4 | 보고서 쉬운 말 요약기 | 약간 겹침 (요약 방식은 비슷, 대상이 보고서) | 별도 서비스. Docklab 연결 여부는 나중에 |
| 5 | 데이터 노트 | 약간 겹침 ("내 기록" 메모와 비슷) | Docklab "심화 노트"로 붙이거나 KITA 스터디와 묶어 따로 운영. 나중에 결정 |

## 2-1. 3차 정리 (2026-11-17): 겹치는 두 개를 빼고 새 아이디어 두 개
| 뺀 아이디어 | 이유 |
|---|---|
| 글로벌 정책 브리핑 (Fact Desk) | Trade News Room의 뉴스 요약과 너무 겹침 |
| 이슈 데이터 노트 (Trade Notebook, `data-notes/`) | Trade Digest(옛 Report Plain)의 보고서 깊게 읽기와 너무 겹침 |

| 검토한 새 아이디어 | 결과 | 이유 |
|---|---|---|
| WTO 분쟁 지도 | 뺌 | 분쟁 소식은 최신 뉴스로도 충분히 알 수 있음 |
| **외교 거리 × 교역 (Alignment Lens, 가칭)** | 채택 | 유엔총회 투표로 본 외교 거리와 교역 비중이 시간에 따라 같이 움직였는지 보는 연구 질문. 데이터 노트의 "질문 하나 깊게 파기"를 고정 질문 하나로 이어받음 |
| **거울 통계 차이 (Mirror Gap, 가칭)** | 채택 | 같은 교역을 두 나라가 각자 신고한 값의 차이를 보여 줌. 한쪽 숫자만 쓰는 뉴스로는 알 수 없고, 통계를 믿기 전에 기록 방식부터 따져 보게 함 |

상세 기획서와 구현 프롬프트는 각 서비스 폴더(`alignment-lens/`, `mirror-gap/`)에 있다.

### Tradeweave 핵심 결정 (자세한 내용: `trade-weave/materials/docs/tradeweave-onepager.md`)
- 대상자: 해외영업 신입 + 국제통상·국제정치에 관심 있는 사람
- 핵심 기능: ① 교역 상대국 지도(수출/수입 전환, 상위 5개) ② 쏠림 정도 보기 ③ 출처·기준연도 표시와 CSV 내려받기
- 첫 화면의 단 하나의 행동: 나라 하나 고르기
- 하지 않을 것: 개인정보 수집, 출처 없는 숫자, 교역량 변화의 원인 단정

## 4. 저장소 · 배포 구조
- GitHub `trade-data-lab` 저장소 하나에 서비스마다 폴더 하나. 로컬은 데스크탑 `vscode 작업/trade-data-lab`
- Vercel은 서비스마다 프로젝트를 따로 만들고 Root Directory를 서비스 폴더로 지정 (Tradeweave 프로젝트: Root Directory `trade-weave`)
- 새 서비스를 배포할 때: 같은 저장소를 새 프로젝트로 Import → Root Directory를 처음부터 서비스 폴더로 → "변경 없으면 배포 건너뛰기" 켜기

## 5. 모든 서비스 공통 원칙
- 숫자에는 출처와 기준연도를 표시한다. 지어낸 데이터, 출처 없는 숫자는 쓰지 않는다.
- 연습용 가상 데이터에는 "가상" 표시를 붙인다.
- 개인정보를 모으지 않는다.
- 원인을 단정하지 않는다. 사실, 해석, 불확실한 것을 나눈다.

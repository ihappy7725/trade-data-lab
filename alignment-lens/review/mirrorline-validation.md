# Mirrorline 첫 사례 검증

검증일: 2026-11-19. 이는 구현·원자료 대조 기록이며 인간의 정치적 해석 검수나 이용 수요 검증이 아니다.

## 자료

- UN Comtrade 중국·미국 원본 JSON을 별도로 읽어 화면 JSON 네 금액과 대조했다. 양국 H5, TOTAL, 연간 2017, partner2=0, customs=C00, mot=0, 원분류 상태와 양방향을 확인했다.
- 중국→미국: 525,764,714,470 − 430,328,146,524 = 95,436,567,946 USD.
- 미국→중국: 154,441,855,874 − 129,797,515,346 = 24,644,340,528 USD.
- 두 차액은 CIF 수입 필드와 FOB 수출 필드의 미조정 차액이다. 운임 추정값이나 통계 오류 금액으로 표시하지 않는다. 미국 원통계 FAS와 Comtrade FOB 필드명도 구분했다.
- Census 원표의 TOTAL 2017: 수입 505,165.1 − 수출 129,997.2 = 적자 375,167.9 (백만 USD). USD로 변환해도 원표 정밀도를 넘어선 값으로 주장하지 않는다.
- USTR PDF 99쪽(본문 91쪽)을 텍스트 추출 및 렌더 이미지로 확인했다. 당시 인용값은 현재 조회값과 따로 보존한다.
- 중국 공식 재게시 백서 II절에서 당시 중국 흑자 및 백서가 인용한 미국 적자 수치를 확인했다. 문서 수치를 고쳐 쓰거나 공통 기준으로 검증됐다고 표시하지 않는다.
- 모든 원본의 SHA-256이 사례 JSON과 일치한다. 원본은 raw/에만 있다.

## 자동 검증

`node review/verify_mirrorline.cjs` 통과:

- 실제 앱의 CSV 함수로 12행 생성. 원본 집계 네 행, 방향별 차액 두 행, Census 참고 세 행, 당시 문서 인용 세 행을 대조했다.
- CSV 정확한 금액, USD·가격 기준·출처·조회일 보존.
- Markdown의 두 방향 차액·원금액·문서 인용값·원문 위치·한계·소스 해시 확인.
- 한/영 네 화면(사례·존재 이유·방법·출처)을 실행. 영문 본문에 한국어 잔존 없음. 언어 버튼의 한국어 전환 표기는 의도된 표시다.
- localStorage 접근 시 예외를 내는 VM 환경에서 실행. 앱은 localStorage에 접근하지 않는다.
- JS 구문 검사 통과. 새 실행 HTML·CSS·JS에서 금지 인과 표현 및 외부 서비스 상대 경로 ../ 검색 0건.

## 실제 브라우저

- 사례 진입, 교역 방향 전환, 정확한 USD 표 펼치기를 실제로 조작하고 표시값을 확인했다.
- 375px에서 사례 및 교역 대조 화면, 방법·출처·존재 이유 화면에 페이지 가로 넘침이 없다.
- 영어 전환과 다크 모드에서 라벨·청록/주황 패턴 구분 확인. 다시 한국어·라이트로 되돌리고 임시 화면 크기 지정을 해제했다.
- 브라우저 오류·경고 로그 없음.
- CSV와 Markdown 직렬화는 실제 앱 코드 실행으로 검사했으며 브라우저의 파일 저장 권한 대화상자를 검증한 것은 아니다.
- review/mirrorline-case.jpg, review/mirrorline-comparison.jpg, review/mirrorline-mobile.jpg에 화면 기록.

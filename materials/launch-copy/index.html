문제0–5초

이 나라는 주로 어디에 팔고, 어디서 사 올까요? 새 시장을 맡으면 가장 먼저 드는 질문입니다.

불편5–12초

그런데 답을 찾으려면 여러 사이트를 돌아야 하고, 찾은 자료마다 연도와 단위가 달라 서로 비교하기도 어렵습니다.

해결12–24초

Tradeweave는 나라 하나만 고르면 주요 교역 상대국을 지도 한 장과 상위 5개국 목록으로 보여 줍니다. 1위 상대국이 차지하는 비중과, 상위 몇 나라에 얼마나 몰려 있는지도 쉬운 말로 풀어 드립니다. 모든 숫자에는 출처와 기준연도를 붙였고, CSV로 내려받을 수 있습니다.

화면: 나라 선택 → 지도 → 쏠림 정도 → 출처 표기 순서로 넘기기

행동24–30초

회원가입은 필요 없습니다. 궁금한 나라 하나, 지금 골라 보세요.

읽을 때

  • "Tradeweave"는 "트레이드위브"로 읽습니다.
  • "5개국", "1위"는 기능 설명이지 순위 자랑이 아닙니다. 실제 나라 이름이나 수치는 넣지 않았습니다.
  • 시간이 남으면 "원인은 단정하지 않고, 달라진 모습만 보여 드립니다"를 해결 구간 끝에 덧붙일 수 있습니다(약 3초).

쓰기 전에 확인할 것

기획서와 대조한 결과

일부러 쓰지 않은 표현

  • "무료": 기획서에는 회원가입이 없다는 말만 있고 요금 이야기는 없습니다. 무료로 운영한다면 그때 넣으면 됩니다.
  • "최신 데이터": 기획서가 "최신" 대신 "기준연도"를 쓰기로 정했습니다.
  • "○○개국 지원": 지원 나라 수는 기획서에 없고 데이터 가공도 끝나지 않았습니다.
  • "실시간", "가장 정확한": 근거가 없어 뺐습니다.

공개 전에 정해야 할 것

  • "런칭"이라는 말: 기획서상 기술 스택과 배포 방식이 아직 정해지지 않았습니다. 실제 공개 전이라면 "곧 공개", "첫 사용자 모집"으로 바꾸는 편이 정확합니다.
  • 기획서 표기 차이: 핵심 기능 3번 설명에는 출처 예시가 "UN Comtrade"로 남아 있지만, 확정된 출처는 CEPII BACI입니다. 문구는 BACI 기준으로 썼고, 기획서도 맞춰 두면 좋습니다.
  • BACI 표기: 이용 조건(Etalab 2.0)상 출처 표시가 필요하므로 게시물 3번 이미지의 출처 줄은 지우지 않는 것을 권합니다.

# 배포 점검표 · Trade Digest (2026-11-16)

주소: https://trade-digest-alpha.vercel.app/

## 1. 저장 시험 (Neon 연동)
| 시험 | 입력 | 결과 | 확인 |
|---|---|---|---|
| 정상 입력 | 보고서 추가: KITA [TF 25호] 베트남 진출 한국 기업 | 저장됨, 표지 벽에 `방문자 추가` 표시 | ✅ Neon `shelf_reports` 줄 생성 |
| 빈 칸 | 모든 칸 비움 | 400, 칸 5개 안내 | ✅ 저장 안 됨 |
| 잘못된 링크 | `http://…` (https 아님) | 400, 링크 안내 | ✅ 저장 안 됨 |
| 잘못된 발간 형식 | `2026/11/01` | 400, 발간 안내 | ✅ 저장 안 됨 |
| 내 서재 잘못된 키 | 형식이 아닌 키 | 400, 키 안내 | ✅ 저장 안 됨 |
| 내 서재 잘못된 링크 | `ftp://…` | 400, 링크 안내 | ✅ 저장 안 됨 |
| 중복 · 두 번 클릭 | 같은 링크 재입력 · 버튼 빠르게 두 번 | 409 또는 한 번만 저장 (코드 적용) | ⏳ 같은 링크를 다시 넣어 보면 확인 가능 |

## 2. 보안 점검
| 항목 | 결과 |
|---|---|
| 원문 PDF · 검수 기록 · DB 설계 파일 노출 | ✅ 404 (막힘) |
| 키 · 연결 주소가 화면 코드에 있는지 | ✅ 없음 (`DATABASE_URL`은 Vercel 환경 변수만) |
| 이름 · 이메일 수집 | ✅ 없음 (내 서재는 브라우저 익명 번호) |

- 요약 · 전망치 숫자는 아직 원문으로 확인되지 않은 것이 많습니다 (검수 전 표시 유지).

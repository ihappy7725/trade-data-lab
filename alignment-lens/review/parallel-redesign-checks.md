# PARALLEL 홈페이지 재구성 · 2026-11-17

## 반영
- 사용자 확정 이름 PARALLEL. 가장 큰 헤더·로고·제목·CSV 파일명·새 저장 키에 적용.
- 첫 화면의 소개 문단·영문 자료 설명·예시 쌍·출처 배지·확인 날짜 제거.
- 전면 선박 사진과 투명 메뉴, 중앙 확대 사진 카드, 대형 타이포와 지구·국가 선택, 넓은 세 칸 탐색 패널, 간단한 푸터.
- 사용자 선택에 따라 기업실적·채용·기업 미디어 섹션 제외.
- 사진 출처·저자·라이선스는 출처 화면과 credits.json에 기록.

## 검증
- 375px에서 홈페이지·지구 구획·쌍·나라 화면의 documentElement.clientWidth와 scrollWidth가 모두 375.
- 한국어·영어 전환. 영문 홈페이지와 출처 화면의 본문에 남은 한글 0건.
- 카드 전환, 새 입력창의 KOR/CHN 비교, 지구 국가 카드 클릭, 기존 국가 화면, 다크·라이트 동작.
- localStorage가 SecurityError를 내는 현재 코드 검사 화면에서 쌍 자료 정상 표시. 콘솔 오류 0건.
- JavaScript 문법, 역사적 코드·비교 규칙 검사, CSV의 30년 210개 숫자와 기존 JSON 대조 통과.
- 화면 금지 문구 0건. 상위 폴더 import 없음. interpretations.json은 빈 객체 유지.

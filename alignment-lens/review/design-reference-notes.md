# 포스코플로우 참고 디자인 검토

확인일: 2026-11-17. 참고 사이트: https://www.poscoflow.com/kr/

브라우저에서 확인한 요소는 흰 바탕·큰 고딕 제목·푸른 핵심 문구로 시작하는 도입부, 영상 히어로, 큰 폭의 섹션 전환, 파란 계열의 브랜드 구간, 이미지 카드와 정렬된 정보 구획이다. 한국어 글꼴의 계산 스타일은 Pretendard였다. 이는 화면 관찰 기록이며 사용성 우수성을 실험으로 확인했다는 뜻은 아니다.

Alignment Lens C 시안에 옮긴 구성:

- 큰 고딕 제목과 짧은 문장으로 첫 질문의 위계를 분명히 한다.
- 흰색·짙은 파랑·밝은 파랑의 대비, 넉넉한 섹션 간격을 쓴다. 색상값은 이 서비스에서 별도로 정한 토큰이다.
- 나라 입력과 실행을 폭이 넓은 한 구획으로 묶어 첫 화면에서 선택할 수 있게 한다.
- 가벼운 둥근 모서리로 입력·그래프·설명을 묶되 그림자는 사용하지 않는다.
- 그래프 영역은 밝은 바탕을 기본으로 두고, 직접 붙이는 라벨과 출처를 읽기 쉽게 배치한다. 다크 모드는 별도 토큰으로 바꾼다.
- 외교 거리와 교역 비중은 파랑·갈색 계열 및 글자 라벨로 구별한다. 색만으로 의미를 전달하지 않는다는 기준은 WCAG 2.2 SC 1.4.1과 맞춘다: https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html
- 모션은 짧고 사용자가 제어할 수 있게 하며 `prefers-reduced-motion`을 따른다. 데이터 값·비교 축을 장식 목적으로 움직이지 않는다.

사진·영상·로고·문구·원본 소스 코드를 복사하지 않았다. 국가별 면적·색 크기를 지어내거나 장식용 추세선을 그리지 않았다. C 시안은 아직 실제 데이터 기능이 없는 디자인 검토용이다.

서체는 외부 파일을 내려받지 않은 로컬 글꼴 스택이다. Pretendard가 설치돼 있지 않으면 시스템 한국어 고딕을 사용한다. 실제 구현의 글꼴 배포 방식은 디자인 선택 후 서비스 내부에서 독립적으로 관리한다.

시안: `review/design-C.html`. 기존 A/B 시안은 비교 기록으로 보존한다. C는 아직 사용자가 확정한 디자인이 아니므로 DESIGN.md를 확정본으로 작성하지 않았다.

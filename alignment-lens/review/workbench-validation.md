# 직접 대조 도구 1차 검증

검증일 2026-11-19. 자료·구현 검증이며 실제 이용 수요 검증이나 사람의 정치적 해석 검수가 아니다.

## 원자료와 범위

- 한국·중국·미국 2017·2018·2023년 연간 상품 전체의 공개 API 응답 9개를 확보했다. 각 응답 4개 기록의 범위·중복·금액·가격 필드를 검사했다.
- 생성기와 별도로 Python Decimal로 원본 JSON을 읽어 Comtrade 36개 금액과 공통 기록을 대조했다. 원본 SHA-256과 수집 manifest가 일치한다.
- 별도로 보존한 Census 참고값 2개는 기존 미·중 사례 조회본의 시점·해시를 그대로 보존했다.
- 국가·연도별 자료가 있다는 것과 상세 품목·월별 자료를 지원한다는 것은 구분한다. 이번에는 상품 전체·연간만 제공한다.

## 자동 검사

- `node review/verify_workbench.cjs`: 공통 기록 38개, 순서 있는 지원 대조 44개와 노트 왕복 44개 통과.
- Decimal 문자열 자릿수 정렬/BigInt 차액, 긴 소수와 큰 금액 정밀도, 음수 차액, 0과 결측 구분 확인.
- 기간·품목·통화·단위 불일치, 결측, 같은 기록 중복의 차액 계산 보류 확인.
- 노트 버전·크기·방향·날짜·공식 출처 도메인·금액·메모 길이를 검사하고 가져온 계산 결과를 무시하는 것을 확인.
- 새 CSV 16행/21열의 일관성, 원래 금액·조건·출처 필드 보존 확인.
- `node review/verify_workbench_runtime.cjs`: 실제 화면 코드의 한/영 시작·대조·존재 이유·방법·출처 렌더링, 저장소 차단 환경, 내부 JSON 요청만 사용, 메모 HTML 이스케이프, 잘못된 파일이 현재 작업을 보존하는 동작 확인.
- JS 구문 검사 및 기존 미·중 사례 회귀 검사 통과.
- 새 실행 코드에서 금지 인과 표현과 외부를 가리키는 ../ 경로 검색 0건.

## 실제 브라우저

- 나라·상대국·연도 선택으로 한국→미국 2023년 대조를 만들었다.
- 금액 A 116,290,387,484 USD / B 119,716,388,241 USD, B−A 3,426,000,757 USD를 원본과 대조했다. 순서를 바꾸면 차액 부호가 반전된다.
- 메모 입력 → 실제 노트 파일 내려받기 → 시작 화면으로 이동 → 실제 파일 선택 → 같은 금액·차액·메모 복원을 확인했다. 실제 다운로드 파일을 별도로 읽어 금액과 메모를 재검사했다.
- 복원한 노트의 ‘현재 내장자료와 다시 대조’에서 원래 값 유지 및 변경 없음 표시를 확인했다. 실시간 조회라고 표시하지 않는다.
- 초기 노트를 만든 뒤 공통 형식에 released_on을 추가했으며, 기존 노트가 보존된 이전 조회본과 계속 대응하는지 확인했다.
- Comtrade/Census의 같은 방향 미국 수입 기록을 대조해 CIF/customs value 차이, 품목분류 미확인을 확인했다. 조회일은 같아도 자료 발표/개정일은 별도로 확인 불가다.
- 잘못된 노트 파일은 메시지를 표시하고 현재 차액을 유지했다.
- 375px에서 입력·대조·방법·출처·존재 이유의 가로 넘침 없음. 영문 본문에 한국어 UI 잔존 없음(사용자 메모는 번역하지 않음). 다크 모드 확인.
- 1280px 데스크톱에서 가로 넘침 없음. 실제 브라우저 오류·경고 로그 없음.

## 남은 범위

품목별 차액 탐색·월별 자료·임의 CSV 불러오기·정식 서비스명·폴더 이름 변경·공개 배포는 아직 하지 않았다. 다른 서비스와 루트 파일, Git stage/commit/push는 변경하지 않았다.

## 절대 규칙: 다른 폴더를 침범하지 않는다
1. 파일을 만들고, 고치고, 지우고, 옮기는 일은 **`mirror-gap/` 안에서만** 한다.
2. 다른 서비스 폴더(`policy-tracker/`, `trade-news-room/`, `trade-weave/`, `trade-digest/`, `alignment-lens/`)의 파일은 **절대 고치거나 지우지 않는다.** 참고로 읽는 것만 된다. 참고한 코드가 필요하면 `mirror-gap/` 안에 복사해서 쓰고, `../다른폴더/...` 같은 경로로 불러오거나 연결하지 않는다.
3. 서비스끼리 코드·데이터·스타일·패키지를 공유하지 않는다. `mirror-gap/`는 다른 폴더가 없어도 혼자 빌드·실행·배포될 수 있어야 한다.
4. 저장소 루트의 파일과 폴더(`README.md`, `CLAUDE.md`, `docs/`, `.github/`, `.gitignore`, `.gitattributes`)는 **먼저 나에게 묻고 승인받은 뒤에만** 바꾼다. 바꿀 필요가 생기면 무엇을 왜 바꿀지 보여 준다. (예: `docs/decisions.md`에 결정 한 줄 추가, GitHub Actions 작업 추가)
5. GitHub Actions 작업을 추가하게 되면(승인 후) `paths: ['mirror-gap/**']`로 이 폴더가 바뀔 때만 돌게 하고, 작업 디렉터리를 `mirror-gap`로 두어 이 폴더 밖에 파일을 쓰지 않게 한다.
6. 패키지 설치(`npm install`, 파이썬 가상환경 등), 원자료(`raw/`), 비밀값(`.env`), 빌드 결과는 모두 `mirror-gap/` 안에 두고, 무시할 파일은 `mirror-gap/.gitignore`에 적는다.
7. 배포는 이 서비스 전용 Vercel 프로젝트(Root Directory = `mirror-gap`)로만 한다. 설정 파일(`vercel.json`, `.vercelignore`)도 `mirror-gap/` 안에 둔다. 다른 서비스의 Vercel 프로젝트나 설정은 건드리지 않는다.
8. 다른 서비스로 가는 링크는 **배포된 웹 주소**로만 건다. 실제 주소는 나에게 확인한다.
9. 다른 폴더에서 버그나 고칠 점을 발견하면 고치지 말고 나에게 알리기만 한다.
10. git: 커밋은 내가 요청할 때만 한다. 이 폴더 파일만 올린다(`git add mirror-gap`; `git add -A`나 `git add .`를 저장소 루트에서 쓰지 않는다). 커밋 전에 `git status --short`로 `mirror-gap/` 밖의 파일이 들어가지 않았는지 확인한다. push, 브랜치 만들기, 기록 고치기(rebase·reset·force push)는 묻고 나서 한다.

## 작업을 마칠 때마다 확인

- [ ] `mirror-gap/` 밖을 가리키는 경로(`../`)가 코드에 없다

# 서비스 한 줄 설명

교역 한 건에는 숫자가 두 개 생긴다. 나라 A가 "B로 이만큼 수출했다"고 신고한 값(X)과, 나라 B가 "A에서 이만큼 수입했다"고 신고한 값(M)이다. 이 서비스는 두 나라를 고르면 X와 M을 나란히 놓고, **얼마나, 어디서, 언제부터** 어긋나는지 보여 준다. 차이의 원인은 단정하지 않고, 알려진 설명 후보와 알 수 없는 부분을 나눠 보여 준다.

- 핵심 질문: 무역 통계는 서로 맞을까? 안 맞는다면 어느 나라 쌍, 어느 품목, 어느 시기에 크게 벌어지나?
- 대상: 해외영업 신입, 국제통상·통계 관심자, 정책대학원 지원 준비생
- 첫 화면에서 할 단 하나의 행동: 두 나라 고르기

# 반드시 지킬 원칙

1. **지어낸 숫자 금지.** 화면의 모든 숫자는 UN Comtrade·CEPII BACI에서 받은 값이어야 한다. 데이터를 받을 수 없는 환경이면 지어내지 말고, 받는 스크립트를 먼저 만든 뒤 나에게 실행을 요청한다.
2. 설명용 예시(특히 "숫자가 왜 다를까" 페이지)에 쓰는 숫자는 화면과 파일 모두에 **"가상"** 표시를 붙인다.
3. 화면의 모든 숫자 옆에 **출처, 기준연도, 받은 날짜**를 붙인다.
4. **원인 단정 금지.** 화면 문구에 "틀렸다, 거짓 신고, 조작, 원인은, ~때문이다, 밝혀졌다, 우회 수출, 원산지 세탁, 밀수, 관세를 피하려고, 제재를 피해"를 쓰지 않는다. 대신 "두 신고값이 다르다, 어긋난다, 설명 후보, 알려진 이유 중 하나, 경유 거점이 낀 쌍, 같은 시기에 차이가 커졌다"를 쓴다. 예외: 방법 페이지에서 "가격 조작·탈세 같은 가능성은 이 자료만으로 판단할 수 없다"고 설명하는 한 문장. 다 만든 뒤 금지어를 검색해 예외 외에는 0인지 확인한다.
5. 어느 나라 통계가 "맞다"고 판정하지 않는다. "의심 국가" 목록·점수를 만들지 않는다. 기업·개인·선박 단위 자료를 쓰지 않는다.
6. **API 키**(`COMTRADE_KEY`)는 `.env`와 GitHub Actions 비밀값에만 둔다. 화면 코드는 미리 만든 JSON만 읽고, 키를 전혀 쓰지 않는다. `.env`는 `.gitignore`에 넣는다.
7. 개인정보 수집, 로그인, 방문자 추적 금지. localStorage는 편의용으로만, 막혀도 동작해야 한다.
8. AI가 해석 문장을 자동으로 지어내 화면에 넣지 않는다. 해석은 사람이 검수해 JSON에 넣은 것만 보여 준다.

# 데이터

## ① UN Comtrade (주 자료)
- 웹: https://comtradeplus.un.org/ · 개발자 포털: https://comtradedeveloper.un.org/
- API:
  - 키 있음: `https://comtradeapi.un.org/data/v1/get/C/A/HS` (헤더 `Ocp-Apim-Subscription-Key`)
  - 키 없음(공개 미리보기): `https://comtradeapi.un.org/public/v1/preview/C/A/HS` — 한 번에 최대 500건, 기간 1개
  - 주요 파라미터: `reporterCode`, `partnerCode`, `period`(연도), `cmdCode`(`TOTAL` 또는 HS 2단위), `flowCode`(`X` 수출, `M` 수입)
- 무료 개인 키의 하루 호출 한도는 공식 안내 기준 500회로 알려져 있다. **정확한 한도와 한 번에 받을 수 있는 건수는 시작할 때 개발자 포털에서 확인**하고 README에 적는다.
- 쓰는 값: `primaryValue`(미국 달러). 신고국의 평가 기준을 그대로 따른다(보통 수입 CIF, 수출 FOB).
- **합계 행만 쓰는 조건**(같은 값을 두 번 더하지 않도록, 코드 한곳에 상수로): `partner2Code == 0`, `customsCode == "C00"`, `motCode == 0`. 응답 필드 이름이 다르면 멈추고 나에게 알린다.
- 호출 사이에 1초 이상 쉬고, 429·한도 초과 응답은 기다렸다가 다시 시도한다(최대 횟수 정해서). 받은 원자료는 `raw/`에 캐시해서 같은 호출을 반복하지 않는다.
- 이용 조건: 시작 전에 Comtrade 이용 약관을 확인해 출처 문구와 재배포 범위를 정하고 나에게 알린다. 원자료 전체는 저장소에 올리지 않는다.

## ② CEPII BACI HS92 (비교선)
- 다운로드: https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=37 · 라이선스 Etalab Open Licence 2.0
- 양쪽 신고값을 바탕으로 수입값의 CIF 부분을 추정해 빼고, 신고국 신뢰도로 가중해 한 거래에 숫자 하나로 맞춘 자료. 열: `t` 연도, `i` 수출국, `j` 수입국, `k` HS6, `v` 천 달러.
- 쌍 화면에 세 번째 표시(맞춘 값)로만 쓴다. 단위를 미국 달러로 맞춘다(천 달러 × 1000).

## ③ 1단계 나라 묶음과 기간
- 한국 + 한국의 상위 교역국 15개 안팎(BACI 최신 연도 기준) + 주요 경유 거점. 정확한 목록은 후보를 만들어 나에게 확인받고, 고른 기준과 함께 `data/meta.json`에 적는다.
- 기간: 최근 10년(연별). 신고가 없는 해는 `null`.

## ④ 나라 코드
- Comtrade 숫자 코드 → ISO3로 바꿔 쓴다. 490("Other Asia, nes")은 대만으로 표시하고 방법 페이지에 적는다.
- "Areas, nes" 등 지역 미상 상대국은 쌍 목록에서 빼되, 비공개 처리 신호 계산에 쓴다.

# 계산 (방향마다 따로: out = A→B, in = B→A)

- `X` = A가 신고한 B로의 수출, `M` = B가 신고한 A로부터의 수입
- 차이 `M − X` (달러)
- **차이율(기본 지표)** `(M − X) ÷ ((M + X) ÷ 2) × 100` (%). 양수 = 수입 쪽이 더 큼
- 배수 `M ÷ X` (보조)
- BACI 위치 `(BACI − X) ÷ (M − X)` — M과 X가 거의 같으면 표시하지 않음
- 한쪽이 신고하지 않은 해: 차이를 계산하지 않고 "{나라} 신고 없음". 0으로 보지 않는다
- 양쪽 값이 아주 작은 쌍은 순위에서 기본 숨김(기준값은 meta.json, 나에게 확인)
- (2단계) HS 2단위 장마다 같은 계산. 각 장이 쌍 전체 차이에서 차지하는 몫을 막대로. 합계 차이와 장별 합의 나머지는 "장에 나눌 수 없는 차이"로 따로 표시

# 설명 후보 규칙

차이가 큰 쌍·해·품목에 "가능한 설명 후보" 칩을 붙인다. **원인 판정이 아니다.** 규칙은 `data/rules.json` 한 파일에 두고, 코드와 방법 페이지가 같은 파일을 읽는다(서로 어긋나지 않게).

| 후보 | 붙이는 조건 |
|---|---|
| 평가 기준 (CIF/FOB) | 수입 쪽이 더 크고 차이율이 작은 범위. 범위 기준은 출처를 찾기 전까지 정하지 말고, 그동안은 모든 쌍에 "기본 설명"으로만 보여 준다 |
| 경유 거점 | 쌍의 한쪽이 `data/hubs.json`에 있을 때. 거점 목록은 항목마다 출처(통계기관·논문)를 붙여 내가 확정한다 |
| 신고 시점 | 차이율 부호가 해마다 번갈아 바뀔 때 |
| 비공개 처리 | 신고국의 지역 미상 상대국 값이 그해 전체의 일정 비율을 넘을 때(비율은 나에게 확인) |
| 품목 분류 (2단계) | 장별 차이는 큰데 합계 차이는 작을 때 |
| 신고 없음 / 개정 | 한쪽이 신고하지 않았거나, 이전에 받은 값과 새로 받은 값이 다를 때 |

"가격 조작·탈세·우회 수출"은 후보로도 자동 표시하지 않는다.

# 기술 구조

- **빌드 없는 정적 사이트.** `index.html` 하나 + 바닐라 JavaScript + SVG 그래프. 외부 라이브러리는 정확한 버전으로 고정한 CDN(cdnjs, jsDelivr, unpkg) 주소만.
- 화면은 서버 함수·데이터베이스·로그인·키 없이 동작. Vercel Root Directory `mirror-gap`.
- 데이터 받기·계산은 파이썬(표준 라이브러리 + pandas). 키는 `.env`에서 읽는다.
- (선택) GitHub Actions로 달마다 다시 받아 바뀌면 커밋. 키는 Actions 비밀값.
- 한/EN 전환, 다크/라이트 전환, 375px 너비에서 가로 스크롤 없음. 주소 `#` 뒤로 화면 전환.

- 메뉴: 서비스 이름 · 숫자가 왜 다를까 · 방법 · 출처 · 한/EN · 다크/라이트
- 큰 제목 "같은 교역, 두 나라의 서로 다른 숫자" + 한 줄 설명
- "수출한 나라"(기본 한국)와 "받은 나라" 검색 상자 + "두 숫자 보기" 버튼
- 작은 거울 그림: 가운데 축을 두고 왼쪽 "A가 적은 수출", 오른쪽 "B가 적은 수입" 막대 모양(숫자 없음)

## ② 쌍 화면 `#pair/{A}/{B}/{year}`
- 머리줄: 방향(A→B / B→A 바꾸기), 연도 선택, 출처 배지
- 거울 막대: X | M, 가운데 점선 = BACI 맞춘 값. 막대마다 "누가 신고한 값인지"를 이름표로
- 큰 숫자: 차이율 · 차이(달러) · 배수
- 연도 그래프: 차이율 선, 0% 기준선 강조, 신고 없는 해는 빈칸
- 설명 후보 칩: 누르면 붙은 규칙 문장이 그대로 보인다
- 사실 / 해석 / 불확실 카드 (아래)
- (2단계) 품목 분해 막대, CSV 내려받기(화면 값 + 출처 줄), Tradeweave·Policyline 링크(실제 주소는 나에게 확인)

## ③ 상대국 순위 `#rank/{A}/{year}`
- 방향(수출/수입), 연도, "작은 쌍 숨기기"
- 가로 막대 목록: 상대국마다 차이율(0 기준 좌우). **기본 정렬은 교역 규모**, 차이율·차이 금액으로 바꿀 수 있음

## ④ 숫자가 왜 다를까 `#why`
가상의 화물 하나가 A국 공장 → 배 → 경유지 → B국 항구로 가는 과정을 단계 카드로. 단계마다 A국 세관과 B국 세관이 무엇을 얼마로 적는지 나란히. 다룰 이유: 평가 기준(CIF/FOB), 상대국 기준(수입국은 원산지, 수출국은 마지막으로 아는 목적지), 재수출·중계, 신고 시점, 비공개 처리, 환율 환산, 품목 분류 차이. 모든 숫자에 "가상" 표시.

## ⑤ 방법 `#method` · ⑥ 출처 `#sources`
계산식, 합계 행 조건, 설명 후보 규칙 전체(`rules.json`에서 읽어 표로), 거점 목록과 출처, 받은 날짜·판, 한계. 출처: UN Comtrade, CEPII BACI(Etalab 2.0), IMTS 2010(유엔 국제상품무역통계 권고: 수입 CIF·수출 FOB, 상대국 기준).

## 사실 · 해석 · 불확실 카드 규칙
- **사실**(자동): `{연도}에 {A}가 신고한 {B}로의 수출은 {X}, {B}가 신고한 {A}로부터의 수입은 {M}이다. 수입 쪽이 {차이} ({차이율}%) 더 {크다/작다}. {처음 연도}에는 차이율이 {값}%였다. 출처: UN Comtrade ({A} 신고, {B} 신고, {받은 날짜} 조회), CEPII BACI HS92 {판}.`
- **해석**: `interpretations.json`에 있는 쌍만. 없으면 "이 쌍에는 아직 검수된 해석이 없습니다."
- **불확실**(공통): 차이가 어느 이유로 얼마만큼 생겼는지는 이 자료로 나눌 수 없다 / 두 나라 신고값 모두 나중에 고쳐질 수 있다 / 어느 쪽 숫자가 맞는지는 판단하지 않는다(쓰임에 따라 고름) / 신고 누락·오류·가격 조작 가능성은 이 화면으로 판단할 수 없다.

# 디자인

- `mirror-gap/DESIGN.md`가 있으면 먼저 읽고 따른다. 없으면 **시안 두 개**를 만들어 내가 고르게 한다. "거울"처럼 가운데 축을 두고 좌우가 마주 보는 구성을 한 시안에 넣는다.
- 공통: 데이터가 주인공, 장식 효과 없음, 색은 CSS 변수(다크 모드 값 따로), X와 M 색은 색약 사용자도 구별되게, 한국어가 잘 읽히는 글꼴.
- 실제 회사 로고, 지어낸 후기, 가짜 사용자 수 금지.

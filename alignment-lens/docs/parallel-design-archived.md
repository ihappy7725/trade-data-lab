# PARALLEL · 2026-11-18 사용자 화면 코멘트 반영

- 선박 히어로와 영상 자리를 제거한다. 기존 IN PARALLEL의 파랑 배경·타이포·곡선으로 1.3초 도입을 보여주고 0.35초 동안 지구 비교 화면으로 전환한다. 도입은 페이지 첫 진입에 한 번만 동작하며 시스템 동작 줄이기 설정·입력 포커스 시 즉시 종료한다. 상단 모션 정지 버튼은 사용자 요청으로 삭제했다.
- 지구 배경의 두 나라 비교가 메인이다. 나라 A·B 검색과 비교 버튼을 눈에 잘 띄게 두고 지구 위 두 카드에 실제 선택한 나라를 표시한다. 처음에는 선택 전 상태이며 예시 국가를 자동으로 넣지 않는다.
- 바로 아래에 ‘한 나라의 교역 상대국’을 둔다. 여러 상대국의 외교 거리·교역 비중을 비교한다는 역할을 한 문장으로 설명한다.
- ‘두 나라, 두 흐름.’을 ‘서비스 둘러보기’로 바꾸고 다섯 메뉴를 한 패널에서 전부 보이게 한다. PC는 다섯 열, 휴대폰은 두 열과 마지막 전체 폭이다. 사진 네 장과 계산식 그림을 서로 다르게 쓴다. 캐러셀은 제거한다.
- ‘같은 시간 위에서.’ 구간은 삭제한다.
- Tradeweave와 PARALLEL은 별도로 유지한다. Tradeweave의 현재 기능은 한 해의 국가별 수출입 상대국·집중도이며 품목 분석이라고 부르지 않는다. PARALLEL은 투표 성향 거리와 교역 비중의 장기 변화에 집중한다.
- 방법 페이지는 쉬운 정의 → 실제 점수 예시 → 한계 → 접을 수 있는 연도·추정 세부사항 순서로 설명한다. 예시 숫자는 원 CSV에서 확인한다.
- 한/영, 시스템 테마·수동 전환, 375px, 개인정보·추적 없음, 자료 없는 해의 결측·자료 출처 규칙은 유지한다.
- 서비스 폴더 rename은 OS에서 거부된 상태다. 실제 폴더는 alignment-lens이며 다른 서비스·저장소 루트 파일은 수정하지 않는다.

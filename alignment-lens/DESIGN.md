# PARALLEL 디자인

2026-11-17 사용자가 기존 C안에서 전면 수정을 요청했다. 서비스 이름은 PARALLEL로 확정했다. 이미지 B의 큰 구획과 배치를 반영하되 기업실적·채용·기업 미디어는 제외하도록 선택했다.

- 첫 화면: 화면을 채우는 바다·선박 배경, 겹쳐 놓은 투명 메뉴, 큰 PARALLEL 이름, 하단의 두 나라 선택. 기존 설명·예시 쌍·자료 배지·확인 날짜는 삭제한다.
- 영상은 가로 항해하는 실제 루핑 클립을 원한다. 유료 생성은 쓰지 않는다. 현재는 출처 있는 사진을 CSS로 가로 배치한다. 영상 제작을 완료했다고 표시하지 않는다. 제작 프롬프트는 docs/hero-video-prompt.md에 둔다. 완성 클립의 연결 코드는 준비한다.
- 흰색 구간: 양쪽 카드가 보이고 중앙 카드가 커지는 사진 탐색 캐러셀. 데이터 화면과 방법으로 실제 연결한다.
- 파랑→남색 구간: 대형 IN / PARALLEL 타이포, 곡선, 지구 이미지와 국가 선택 카드. 국가 카드는 지도상 좌표나 교역량을 표현하지 않는 선택 메뉴다. 가짜 기업실적·사용자 수는 넣지 않는다.
- 다음 흰색 구간: 넓은 사진 패널을 세 칸으로 나누고 쌍 비교·나라 탐색·방법으로 연결한다. 같은 카드 반복이나 기업용 섹션은 넣지 않는다.
- 푸터는 이름과 실제 기능·출처 링크만 둔다. 사진의 저자·라이선스·수정 내용은 출처 화면에 둔다. 그래프의 출처·판·기준연도는 유지한다.
- 다크·라이트, 한국어·영어, 375px, 키보드, 모션 정지와 prefers-reduced-motion을 유지한다. 스크롤을 가로채지 않는다. 데이터 선은 장식으로 움직이지 않는다.
- 서비스 폴더 이름도 parallel로 변경하도록 사용자가 요청했다. 현재 환경의 디렉터리 rename이 운영체제에서 거부되어 폴더 변경은 미완료다. 루트 파일과 다른 서비스는 수정하지 않는다.

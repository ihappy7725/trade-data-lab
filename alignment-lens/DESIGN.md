# Alignment Lens 디자인

2026-11-17 사용자가 C안을 선택했고, 이어서 참고 사이트의 화려한 모션과 물류 사진을 반영하도록 요청했다.

- 참고: https://www.poscoflow.com/kr/ 의 큰 고딕 제목, 여백, 큰 이미지 구획, 파랑 중심의 섹션 대비와 사진이 펼쳐지는 연출.
- 짙은 네이비·흰색·밝은 파랑을 기본 토큰으로 사용한다. 데이터 그래프의 색은 별도 토큰으로 두고 직접 이름표와 선 모양을 함께 쓴다.
- 첫 화면의 단일 행동은 두 나라 선택이다. 사진·제목 연출 중에도 입력과 실행은 사용할 수 있어야 한다.
- 물류 사진은 배경을 설명하는 이미지다. 선택한 국가 쌍이나 해당 연도의 실제 교역을 촬영한 사진처럼 표시하지 않는다. 촬영지·저자·라이선스·변경 내용을 출처에 기록한다.
- 사진 도입부는 클립 확장, 순차 등장, 느린 이미지 이동을 쓴다. 데이터 값·축은 장식 목적으로 움직이지 않는다. 스크롤을 가로채지 않는다.
- 모션 중지 버튼과 prefers-reduced-motion을 지원한다. 움직임을 줄여도 내용·나라 선택이 모두 보인다.
- 실제 회사 로고를 서비스 장식으로 넣지 않는다. 사진 속 문자·상표가 중심이 되지 않는 구도를 사용한다.
- 첫 화면은 큰 타이포와 넓은 선택 구획, 쌍 화면은 위아래 SVG 그래프와 사실·해석·불확실 카드로 구성한다.
- 그림자·빛 번짐·3D 장식은 사용하지 않는다. 다크 모드는 별도 토큰으로 정의한다.
- 375px에서 가로 스크롤 없이 표시한다. 작은 화면에서도 실행 버튼이 사진 연출 뒤로 밀리지 않게 한다.
- 국가 이름과 출처는 한국어가 읽기 쉬운 로컬 글꼴을 우선 사용한다. 외부 글꼴을 도입하면 버전·라이선스와 서비스 내부 독립성을 확인한다.
